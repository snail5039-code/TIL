Day24 · Python_08

오늘은 TMDB API 문제를 강사님 풀이와 같이 다시 봤다. 핵심은 endpoint를 외우는 게 아니라 문서에서 필요한 path를 찾는 감각이었다.

`fetch_tmdb_api()`를 만들어두니 now_playing, credits, genre list를 같은 방식으로 다룰 수 있었다.

다음에 다시 볼 것: 요청을 너무 많이 보내지 않는 구조. 특히 detail API를 for문 안에서 무작정 부르는 건 조심.
가장 따뜻함. 개발 블로그보다 공부 공책에 가깝게 만들고 싶으면 좋다.
