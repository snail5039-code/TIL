## 1. 수직/수평 정렬 (Flexbox 활용)
**Flexbox**는 컨테이너 내부 아이템들의 공간 배분과 정렬을 쉽게 할 수 있도록 설계된 1차원 레이아웃 모델입니다.

| **정렬 속성** | **설명** |
| --- | --- |
| `display: flex;` | 부모 요소를 **Flex 컨테이너**로 지정합니다. |
| `justify-content` | 메인 축(기본값은 수평)을 따라 아이템들을 **수평 정렬**합니다. (`flex-start`, `flex-end`, `center`, `space-between`, `space-around`, `space-evenly`) |
| `align-items` | 교차 축(기본값은 수직)을 따라 아이템들을 **수직 정렬**합니다. (`flex-start`, `flex-end`, `center`, `baseline`, `stretch`) |

### 예시 코드
**HTML**
```html
HTML

`<div class="flex-container">
    <div class="item">Item 1</div>
    <div class="item">Item 2</div>
    <div class="item">Item 3</div>
</div>`
```
**CSS**
```css
CSS

`.flex-container {
    display: flex;
    height: 200px; /* 수직 정렬을 위해 높이 지정 */
    border: 1px solid #ccc;
    
    /* 수평 중앙 정렬 */
    justify-content: center;
    
    /* 수직 중앙 정렬 */
    align-items: center; 
}

.item {
    padding: 10px;
    margin: 5px;
    background-color: lightblue;
}`
```

## 2. 미디어 쿼리 및 반응형 디자인
**미디어 쿼리**는 뷰포트(화면) 크기나 장치 유형 등 특정 조건에 따라 다른 스타일을 적용할 수 있게 해주는 CSS 기술입니다.
### 줄어들기 정렬 (특정 너비 이하에서 수평 간격 재배치)
화면 너비가 \$800\\text\{px\}\$ 이하일 때, 메뉴 항목들을 균등하게 분산하여 정렬합니다.
**CSS**
```css
CSS

`/* 기본 스타일 (800px 초과) */
.menu-box > ul {
    display: flex;
    list-style: none;
    padding: 0;
    justify-content: flex-start; /* 기본 정렬 */
}

/* 뷰포트 너비가 800px 이하일 때 적용 */
@media (max-width: 800px) {
    .menu-box > ul {
        justify-content: space-around; /* 아이템 주변에 균등한 공간 할당 */
    }
}`
```
### 줄어들다 세로 중앙 정렬 (특정 너비 이하에서 세로 레이아웃 및 텍스트 중앙 정렬)
화면 너비가 \$600\\text\{px\}\$ 이하일 때, Flex 아이템들을 세로로 쌓고 텍스트를 중앙 정렬합니다.
**CSS**
```css
CSS

`/* 뷰포트 너비가 600px 이하일 때 적용 */
@media (max-width: 600px) {
    .menu-box > ul {
        flex-direction: column; /* 아이템들을 수직으로 배치 */
        /* text-align: center; 는 flex 아이템 내부의 인라인 콘텐츠를 중앙 정렬합니다.
           아이템 자체의 수평 중앙 정렬은 align-items: center; 로 가능하지만,
           flex-direction: column; 일 때는 align-items가 수평 정렬 역할을 합니다. */
    }
    .menu-box > ul > li {
        text-align: center; /* li 내부 텍스트 중앙 정렬 */
    }
}`
```

## 3. 테두리를 이용한 입체감 (사이 선 만들기)
`border-top`과 `border-bottom`에 서로 다른 투명도를 가진 색상(`rgba`)을 사용하여 구분선에 **미묘한 입체감**이나 깊이감을 줄 수 있습니다.
**CSS**
```css
CSS

`.menu-box > ul > li {
    padding: 10px; /* 경계를 더 잘 보이게 하기 위해 패딩 추가 */
    
    /* 상단 경계: 어두운 색(검은색)의 투명도를 낮춰서 그림자처럼 표현 */
    border-top: 1px solid rgba(0, 0, 0, .2); 
    
    /* 하단 경계: 밝은 색(흰색)의 투명도를 낮춰서 하이라이트처럼 표현 */
    border-bottom: 1px solid rgba(255, 255, 255, .2); 
}`
```

## 4. 웹 폰트 사용법
**웹 폰트**는 사용자의 컴퓨터에 설치되어 있지 않아도 웹 페이지에서 특정 글꼴을 사용할 수 있게 해줍니다. **Google Fonts**나 **눈누** 같은 서비스에서 원하는 폰트를 찾아 사용할 수 있습니다.
1. 폰트 제공 서비스에서 원하는 폰트의 `<link>` 태그를 HTML `<head>`에 추가합니다.
2. CSS의 `font-family` 속성으로 해당 폰트 이름을 지정합니다.
### 예시 코드
**HTML** (Google Fonts Noto Sans KR 추가 예시)
```html
HTML
<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>웹 폰트 예시</title>
    <link href="https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;700&display=swap" rel="stylesheet">
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <h1>웹 폰트가 적용된 제목</h1>
    <p>이 텍스트는 Noto Sans KR 폰트로 표시됩니다.</p>
</body>
</html>
```

**CSS** (`style.css`)
```css
CSS

`/* 폰트 지정: Noto Sans KR이 없다면 sans-serif를 사용 */
body {
    font-family: "Noto Sans KR", sans-serif; 
}

h1 {
    font-weight: 700; /* 폰트 두께 지정 (폰트 링크에서 가져온 두께여야 함) */
}`
```

## 5. 아이콘 사용법 (Font Awesome 예시)
- \*폰트어썸(Font Awesome)\*\*은 아이콘을 폰트나 SVG 형태로 제공하는 라이브러리입니다. 폰트처럼 크기와 색상을 CSS로 쉽게 변경할 수 있습니다. **cdnjs** 등 CDN을 통해 라이브러리 파일을 불러와 사용할 수 있습니다.
1. Font Awesome CDN 링크를 HTML `<head>`에 추가합니다.
2. 사용할 아이콘의 클래스 이름을 HTML 요소(`<i>` 또는 `<span>`)에 적용합니다.
3. `font-size`나 `color` 속성으로 크기 및 색상을 조절합니다.
### 예시 코드
**HTML** (Font Awesome CDN 링크 추가 및 아이콘 사용)
```html
HTML

`<!DOCTYPE html>
<html lang="ko">
<head>
    <meta charset="UTF-8">
    <title>폰트어썸 예시</title>
    <link rel="stylesheet" href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css">
    <link rel="stylesheet" href="style.css">
</head>
<body>
    <i class="fas fa-home home-icon"></i>
    <p>홈 아이콘</p>
</body>
</html>`
```
**CSS** (`style.css`)
```css
CSS

`.home-icon {
    /* 폰트 크기로 아이콘 크기 조절 */
    font-size: 3em; 
    /* 색상 변경 */
    color: #4CAF50;
}`
```

## 6. 전반적인 스타일 라이브러리 (유틸리티 우선 CSS 프레임워크)
질문하신 "전반적인 스타일에 대한 것들이 만들어져 있는" 라이브러리의 대표적인 예는 **유틸리티 우선(Utility-First)** CSS 프레임워크인 **Tailwind CSS**입니다. **daisyUI**는 Tailwind CSS의 플러그인으로, 미리 만들어진 컴포넌트 클래스(버튼, 모달 등)를 제공하여 Tailwind의 단점을 보완합니다.
### Tailwind CSS와 daisyUI
- **Tailwind CSS**: 미리 정의된 CSS 속성(예: `m-4`는 `margin: 1rem;`, `flex`는 `display: flex;`)을 나타내는 수많은 **유틸리티 클래스**를 HTML에 직접 적용하여 스타일을 빠르게 구축합니다.
- **daisyUI**: Tailwind CSS 위에서 동작하며, 버튼이나 드롭다운 같은 UI 컴포넌트 스타일을 제공하여, Tailwind의 유틸리티 클래스만으로 복잡한 컴포넌트를 만드는 수고를 줄여줍니다.
### 예시 코드 (Tailwind CSS 스타일링)
별도의 CSS 파일 작성 없이, HTML 요소에 Tailwind 클래스를 직접 적용합니다.
**HTML** (Tailwind CSS 클래스 사용 예시)
```html
HTML

`<div class="p-6 bg-blue-500 text-white rounded-lg shadow-xl text-xl">
    Tailwind CSS로 스타일링된 박스
</div>`
```
