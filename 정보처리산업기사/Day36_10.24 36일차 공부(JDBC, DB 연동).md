## 1. 순수한 HTML로 정말 웹을 만들 수 없느냐?
**결론:** 데이터베이스 연동, 사용자 맞춤형 콘텐츠 제공 등 **동적인 기능**이 필요한 웹 애플리케이션은 **순수한 HTML만으로는 만들 수 없습니다.**

| **구분** | **순수 HTML** | **JSP (JavaServer Pages)** |
| --- | --- | --- |
| **정적 콘텐츠** | ✅ 가능 (구조와 내용) | ✅ 가능 |
| **동적 콘텐츠** | ❌ **불가능** (서버에서 실시간으로 데이터를 생성할 수 없음) | ✅ **가능** (Java 코드를 사용하여 데이터 처리 및 화면 출력) |
| **데이터베이스 연동** | ❌ **불가능** | ✅ **가능** (Java/JDBC 사용) |
| **주요 용도** | 단순 소개 페이지, 정적인 정보 제공 웹사이트 | 회원 관리, 쇼핑몰, 게시판 등 데이터 기반의 동적 웹 애플리케이션 |

## 2. JSP와 JDBC를 이용한 데이터베이스 연동 정리
제공된 메모는 Java 기반 웹 개발에서 데이터베이스(DB)와 상호작용하는 핵심적인 방법을 설명하고 있습니다.
### A. DB 연결을 위한 기본 사항
서블릿(Servlet) 또는 JSP는 데이터베이스에 접근하기 위해 다음 정보를 알아야 합니다.
- **주소, 데이터베이스, 아이피, 포트:** 데이터베이스 서버의 위치 정보
- **로그인:** 데이터베이스에 접속할 사용자 계정 (ID와 비밀번호)
### B. JDBC 라이브러리 (Java Database Connectivity)
**역할:** 자바 애플리케이션(JSP/Servlet)과 다양한 종류의 데이터베이스를 연결하고 SQL 명령을 수행할 수 있게 해주는 표준 인터페이스입니다.
### 1. 연결 및 조회 코드 구조
Java
```java
try{
    // 1. JDBC 드라이버 로드 (DB 종류에 따라 클래스 이름이 다름. 여기서는 MySQL)
    Class.forName("com.mysql.cj.jdbc.Driver");
    
    // 2. DB 연결 객체 생성 (주소, 계정, 비밀번호)
    // "jdbc:mysql://localhost:3306/mysql" : DB 연결 URL
    Connection con = DriverManager.getConnection("jdbc:mysql://localhost:3306/mysql","root","");

    // 3. SQL 명령을 실행할 Statement 객체 생성
    Statement stmt = con.createStatement();
    
    // 4. SQL 실행 및 결과 집합(ResultSet) 받기 (조회)
    // now() 함수로 현재 시간을 조회하는 예시
    ResultSet rs = stmt.executeQuery("select now() from dual");
    
    // 5. 결과 집합(rs) 처리
    while(rs.next()){
        // rs.getString(1)은 조회 결과의 첫 번째 컬럼 데이터를 가져옴
        System.out.println(rs.getString(1));
    }
    
    // 6. 자원 반납 (가장 나중에 사용한 것부터 닫는 것이 일반적)
    stmt.close();
    con.close();
    
}catch(Exception e){
    e.printStackTrace(); // 예외 발생 시 에러 추적
}
```

### 2. SQL 실행 결과 해석

| **SQL 유형** | **결과** | **메모** |
| --- | --- | --- |
| `ResultSet` | 여러 컬럼의 데이터 한 줄, 여러 줄의 데이터 | `SELECT` 문 실행 결과. 조회된 데이터를 **순회**하며 처리함. |
| **한 개의 컬럼 데이터 하나** | 단일 값 | `ResultSet`에서 `getString(1)` 등으로 접근 가능. |

### C. 데이터 조작 (추가, 삭제, 수정)
`SELECT`를 제외한 데이터 변경 작업은 `executeQuery()` 대신 `executeUpdate()` 메소드를 사용합니다. 이 메소드는 영향을 받은 행의 개수를 반환합니다.

| **작업** | **JDBC 메소드** | **SQL 예시** |
| --- | --- | --- |
| **추가 (삽입)** | `stmt.executeUpdate("인설트 문 집어 넣기")` | `INSERT INTO table (col1) VALUES ('value')` |
| **삭제** | `stmt.executeUpdate("delete from article where id = 13")` | `DELETE FROM table WHERE id = 13` |
| **수정** | `stmt.executeUpdate("저기 안에 업데이트 문 넣으면 됨")` | `UPDATE table SET col1 = 'new_value' WHERE id = 1` |

## 3. 경로 (URL) 지정 방식

| **경로 유형** | **설명** | **예시** | **비고** |
| --- | --- | --- | --- |
| **상대 경로** | 현재 파일 위치를 기준으로 이동하는 주소 (`../`는 상위 폴더) | `../경로 주소` | 경로가 바뀌면 문제가 생기기 쉬움. |
| **절대 경로** | 웹 애플리케이션의 최상위 경로를 기준으로 이동하는 주소 | `<%= request.getContextPath() %>/user/article/list` | **권장.** 경로 변경에 유연하며, JSP/Servlet 환경에서 안정적임. |

### 권장되는 절대 경로 코드
웹 애플리케이션이 배포된 \*\*루트 경로(Context Path)\*\*를 기준으로 링크를 생성하는 것이 가장 안전하고 좋습니다.
```java
`<a href="<%= request.getContextPath() %>/user/article/list">게시글 목록으로 이동</a>`
```
