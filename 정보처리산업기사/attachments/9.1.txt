* 후위연산자, 전위 연산자
int i = 0;

- i++ 
* 현재 이 연산자가 포함된 코드가 실행된 후에 연산을 수행
* 출력문에서 출력시 먼저 i를 출력하니 최초에는 0이 나오나 그 다음 출력에서는 1을 더한값이 나온다.

-++i 
* 현재 이 연산자가 먼저 실행된 후에 코드가 실행 

* 보통 전위 연산자는 잘 쓰지 않는다.

반복문
조건을 만족하는 동안 반복하는 문법 
* 반복문 필수 3요소
1.종료 조건 
2. 초기값
3. 스텝

while, for
* while (조건식, 논리 데이터) { 

}

ex) while (2>1) {
	출력 1
}

int i = 1;
while (i <= 5) {
	출력 i
}
무한 루프
* 값이 변하지 않아 무한 루프에 빠짐
int i = 1;
while (i <= 5) {
	출력 i
	i++;
}
* i값이 1~ 5까지 1씩 증가하며 총 5번 반복하는 반복문
* 5까지 하고 출력이 멈춤 

# 안녕하세요 3번 반복
int j = 1;
    
    while(j < 4) {
    	System.out.println("안녕하세요");
    	j++;
    }
