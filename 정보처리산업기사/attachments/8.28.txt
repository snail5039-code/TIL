실제 개발에 필요한 도구
1. 자바 설치
* JAVA - 프로그래밍 언어 
  언어는 왜 필요한가? 
  - 컴퓨터와 소통하려고
* 컴퓨터가 java를 알아먹을 수 있게 해주는 것(설치 이유)
  java만 있다고 되는 것이 아님 

  자바 개발용 도구(Java Development kit = jdk)까지 설치 해야 소통 가능 
  Java Development kit = jdk(개발, 실행 가능)
  Java Runtime Environment- jre(자바 실행 환경, 서버 실행)

* 자바라는 언어를 활용해서 컴퓨터와 소통하려면 코드 작성 
- 코드 어디에 작성? jdk가 설치되있으면 메모장에서도 작성 후  cmd에서 가능하나 불편하다
 
2. STS(이클립스 기반) 설치   
IDE - 통합개발환경
* 코드 작성, 번역, 실행 결과를 할 수 있는 프로그램
* 이클립스, 인텔리J, STS(이클립스 기반) 프로그램 등이 있음  
- 인텔리J : 무료도 있으나 제한사항이 있다.

sts 설치 후 세팅
enco = encoding 번역 느낌(UTF-8) 




C언어 - 저급언어(컴퓨터 친화적)
- 모든 언어의 기초는 C언어 
- 불편하지만 쓰는 이유, 기계 친화적(임베디드 특화)

고급언어(사람 친화적)
자바 (java -version)-> 있는지 확인하는 것, * 웹 특화
- 제한사항이 많다.
* 처음 만들 때 어렵지만 만들어 놓고 나면 관리가 편함 (유지보수)
* 웹은 변화에 민감, 빠르다. 
ex) 이 컵에는 콜라만 들어가있어

파이썬 * 웹에 특화X,  인공지능(프로토타입), 빅데이터 특화
- 제한사항이 거의 없다.
- 요새는 파이썬으로도 웹을 많이 만듬
* 장고라는 어플이 나와서 보완됨
ex) 이 컵에는 콜라든 사이다든 다들어갈 수 있어
