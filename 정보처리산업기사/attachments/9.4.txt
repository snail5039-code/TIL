인스턴스 변수 
* 클래스(설계도)에 변수를 만들면 설계도를 기반으로 만들어진 객체(인스턴스)는 해당 변수를 가지고 있다.
- 인스턴스가 가지는 변수
- 객체를 만들지 않고는 쓸 수없다.

인스턴스 메서드
* 클래스(설계도)에 메서드를 만들면 설계도를 기반으로 만들어진 객체(인스턴스)는 해당 메서드를 가지고 있다.
- 인스턴스가 가지는 메서드
- 객체를 만들지 않고는 쓸 수 없다.

- 인스턴스  설명 자료 사진 첨부

static
정적 - 멈춰있다.
실제로 멈춰있어서 
한번 할당받은 곳에서 안 움직인다.
프로그램이 시작될 때 생성되서 자리를 잡은 뒤에 프로그램이 끝날 때까지 안 움직이고 고정되어 있다.
static 방식으로의 접근 - 인스턴스를 생성하지 않고 클래스에게 직접 불러낸다.
static 변수는 모든 인스턴스가 공유
static 메서드에서는 static 변수만 사용 할 수 있다.

장점 : 
- 인스턴스를 생성하지 않아도 사용 가능
- 실행속도가 빠르다.

단점 :
- 메모리 관리를 효율적으로 할 수 없다.
- 언어가 가진 본질을 흐린다.
static 메서드를 사용하는 경우
아무리 지속적으로 많이 사용하는 메서드라 할지라도 static 메서드 자체가 가지는 내용이 너무 많다면
staticl이 안좋을 수 있다.

* 콘솔로 동작하는 게시판, 게시즐 작성, 날짜, 시간
