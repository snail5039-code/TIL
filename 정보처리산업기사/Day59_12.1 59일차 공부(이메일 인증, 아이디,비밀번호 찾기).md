## 🔑 비밀번호 찾기 기능 구현 정리 (Spring Boot + MyBatis)
Spring Boot와 MVC 패턴을 이용하여 이메일을 통한 비밀번호 찾기 기능을 구현하는 데 필요한 핵심 단계와 코드를 정리하고 추가적인 고려사항을 제시합니다.

---

### 1. ⚙️ 의존성 및 설정 추가
### 1.1. JavaMailSender 의존성 추가
`pom.xml` 또는 `build.gradle`에 Spring Boot Mail Starter 의존성을 추가합니다.
- **Maven (****`pom.xml`****):**
XML
```javascript
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-mail</artifactId>
</dependency>
```
### 1.2. YAML 설정 (application.yml)
메일 전송에 필요한 계정 정보와 설정을 `application.yml`에 추가합니다.
YAML
```javascript
spring:
  mail:
    host: smtp.gmail.com # 또는 사용하는 SMTP 서버 주소
    port: 587
    username: your-email@example.com # 실제 이메일 주소
    password: your-app-password # 이메일 계정 비밀번호 또는 앱 비밀번호
    properties:
      mail:
        smtp:
          auth: true
          starttls:
            enable: true
```

> ⚠️ 주의: Gmail 등을 사용하는 경우, 일반 비밀번호 대신 앱 비밀번호를 생성하여 사용해야 보안 위험을 줄일 수 있습니다.

### 2. 📝 데이터베이스 (회원 테이블)
### 2.1. `MEMBER` 테이블에 `EMAIL` 컬럼 추가
사용자의 이메일 주소를 저장할 컬럼을 추가합니다. 이메일을 통해 사용자를 식별하고 임시 비밀번호를 전송하는 데 사용됩니다.
SQL
`ALTER TABLE MEMBER ADD COLUMN EMAIL VARCHAR(255) UNIQUE NOT NULL;`
> 팁: EMAIL 컬럼은 중복을 막기 위해 UNIQUE 제약 조건을, 필수 정보이므로 NOT NULL 제약 조건을 추가하는 것이 좋습니다.

### 3. 📧 비밀번호 찾기 로직 구현
### 3.1. 임시 비밀번호 생성 유틸리티
비밀번호 찾기 시 사용자에게 발급할 **임시 비밀번호**를 생성하는 유틸리티 클래스입니다.
Java
```javascript
// TempPasswordGenerator.java
public class TempPasswordGenerator {

    private static final String CHARACTERS = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789!@#$%^&*()";
    private static final int LENGTH = 10;

    public static String generate() {
        SecureRandom random = new SecureRandom();
        StringBuilder sb = new StringBuilder(LENGTH);
        for (int i = 0; i < LENGTH; i++) {
            sb.append(CHARACTERS.charAt(random.nextInt(CHARACTERS.length())));
        }
        return sb.toString();
    }
}
```
### 3.2. MyBatis DAO/Mapper (데이터 처리)
`MEMBER` 테이블에서 이메일로 회원을 조회하고, 임시 비밀번호로 업데이트하는 쿼리입니다. XML을 사용하지 않고 Mapper 인터페이스에 `@Update`, `@Select` 어노테이션을 사용하여 직접 쿼리를 정의합니다.
Java
```javascript
// MemberMapper.java
@Mapper
public interface MemberMapper {

    // 1. 이메일로 회원 존재 여부 확인 및 정보 조회
    @Select("SELECT * FROM MEMBER WHERE EMAIL = #{email}")
    Member findByEmail(@Param("email") String email);

    // 2. 임시 비밀번호로 회원 비밀번호 업데이트 (암호화 필수)
    @Update("UPDATE MEMBER SET PASSWORD = #{tempPassword} WHERE EMAIL = #{email}")
    int updatePasswordByEmail(@Param("email") String email, @Param("tempPassword") String tempPassword);
}
```

### 3.3. Service (비즈니스 로직)
비밀번호 찾기 및 이메일 전송의 핵심 로직을 담당합니다. **반드시 임시 비밀번호를 데이터베이스에 저장할 때 암호화해야 합니다.**
Java
```javascript
// MemberService.java
@Service
@Transactional
@RequiredArgsConstructor
public class MemberService {

    private final MemberMapper memberMapper;
    private final JavaMailSender mailSender;
    private final PasswordEncoder passwordEncoder; // 암호화를 위한 Bean

    public void findPasswordAndSendEmail(String email) throws MessagingException {
        // 1. 이메일로 회원 조회
        Member member = memberMapper.findByEmail(email);
        if (member == null) {
            throw new IllegalArgumentException("존재하지 않는 이메일 주소입니다.");
        }

        // 2. 임시 비밀번호 생성
        String tempPassword = TempPasswordGenerator.generate();
        String encodedPassword = passwordEncoder.encode(tempPassword); // ★ 비밀번호 암호화

        // 3. DB에 암호화된 비밀번호로 업데이트
        memberMapper.updatePasswordByEmail(email, encodedPassword);

        // 4. 사용자에게 임시 비밀번호 이메일 전송
        sendTempPasswordEmail(email, tempPassword);
    }

    private void sendTempPasswordEmail(String toEmail, String tempPassword) throws MessagingException {
        MimeMessage message = mailSender.createMimeMessage();
        MimeMessageHelper helper = new MimeMessageHelper(message, "utf-8");

        helper.setTo(toEmail);
        helper.setSubject("임시 비밀번호가 발급되었습니다.");
        
        // 이메일 내용 구성 (HTML 사용 가능)
        String htmlContent = "<h1>임시 비밀번호 안내</h1>"
                           + "<p>새 임시 비밀번호는 **" + tempPassword + "** 입니다.</p>"
                           + "<p>로그인 후 즉시 비밀번호를 변경해 주세요.</p>";
                           
        helper.setText(htmlContent, true); // true: HTML 형식 사용
        mailSender.send(message);
    }
}
```

### 3.4. Controller (요청 처리)
클라이언트의 비밀번호 찾기 요청을 받아 Service 계층에 위임합니다.
Java
```javascript
// MemberController.java
@Controller
@RequiredArgsConstructor
public class MemberController {

    private final MemberService memberService;

    // 비밀번호 찾기 폼을 보여주는 메소드
    @GetMapping("/findPassword")
    public String findPasswordForm() {
        return "member/findPasswordForm"; // findPasswordForm.html (Thymeleaf 등)
    }

    // 비밀번호 찾기 요청 처리
    @PostMapping("/findPassword")
    public String findPassword(@RequestParam("email") String email, Model model) {
        try {
            memberService.findPasswordAndSendEmail(email);
            model.addAttribute("message", "이메일로 임시 비밀번호가 발송되었습니다.");
            return "member/login"; // 성공 후 로그인 페이지로 리다이렉트
        } catch (IllegalArgumentException e) {
            model.addAttribute("error", e.getMessage());
            return "member/findPasswordForm"; // 실패 시 폼 페이지 유지
        } catch (MessagingException e) {
             model.addAttribute("error", "이메일 전송에 실패했습니다. 관리자에게 문의하세요.");
            return "member/findPasswordForm"; 
        }
    }
}
```

### 4. ✨ 추가 고려사항
1. **🔒 비밀번호 암호화:** `MemberService`에서 사용했듯이, 데이터베이스에 **절대 평문 비밀번호를 저장해서는 안 됩니다.** Spring Security의 `BCryptPasswordEncoder`와 같은 강력한 암호화 메커니즘을 사용해야 합니다.
2. **⏳ 임시 비밀번호 유효성:** 임시 비밀번호 발급 시, 해당 비밀번호는 **일회성**이거나 **특정 시간 동안만 유효**하도록 추가적인 검증 로직을 구현하는 것이 좋습니다 (예: `MEMBER` 테이블에 `password_expire_date` 컬럼 추가).
3. **🖼️ 템플릿 엔진 사용:** `sendTempPasswordEmail`에서 HTML 코드를 직접 작성하는 것보다 **Thymeleaf**나 **FreeMarker** 같은 템플릿 엔진을 사용하여 이메일 내용을 작성하면 유지 보수가 훨씬 용이합니다.
4. **📧 이메일 서버 보안:** `application.yml`에 기입하는 이메일 계정 정보는 외부에 노출되지 않도록 **GitHub와 같은 저장소에 올릴 때 주의**해야 하며, 로컬 환경에서만 테스트하고 실제 운영 환경에서는 환경 변수를 사용하는 것이 안전합니다.
궁극적으로는 사용자가 임시 비밀번호로 로그인한 후 **즉시 새 비밀번호를 설정하도록 강제**하는 로직(예: 첫 로그인 여부 플래그 사용)을 추가하여 보안을 강화해야 합니다.
