## 💾 Spring Boot 프로젝트 설정 및 JDBC 설치
Spring Boot 프로젝트에서 데이터베이스 연결을 위해 **JDBC 드라이버**를 설정해야 합니다.
### 설치 방법 (Gradle/Maven)

| **도구** | **설정 내용** | **설명** |
| --- | --- | --- |
| **Maven** | `pom.xml` 파일의 `<dependencies>` 섹션에 추가 | 사용하는 데이터베이스에 맞는 JDBC 드라이버 의존성을 추가합니다. (예: MySQL, PostgreSQL, H2 등) |
| **Gradle** | `build.gradle` 파일의 `dependencies` 블록에 추가 |  |

> 예시 (Maven - MySQL 드라이버):
```xml
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
    <scope>runtime</scope>
</dependency>
```

### 📝 추가 설명: 데이터베이스 연결 설정
JDBC 드라이버 설치 후에는 `src/main/resources/application.properties` 또는 `application.yml` 파일에 **데이터베이스 연결 정보**를 설정해야 합니다.
- `spring.datasource.url`: 데이터베이스 접속 URL
- `spring.datasource.username`: 사용자 이름
- `spring.datasource.password`: 비밀번호
- `spring.datasource.driver-class-name`: JDBC 드라이버 클래스 이름 (예: `com.mysql.cj.jdbc.Driver`)

## 🛠️ MyBatis 설치 및 설정
MyBatis는 SQL 매핑 프레임워크로, JDBC 코드를 단순화하고 SQL을 효율적으로 관리할 수 있게 해줍니다.
### 설치 방법 (Gradle/Maven)

| **도구** | **설정 내용** | **설명** |
| --- | --- | --- |
| **Maven** | `pom.xml` 파일의 `<dependencies>` 섹션에 추가 | Spring Boot에서 MyBatis를 사용하기 위한 스타터 의존성을 추가합니다. |
| **Gradle** | `build.gradle` 파일의 `dependencies` 블록에 추가 |  |

> 예시 (Maven - MyBatis Spring Boot Starter):
```xml
<dependency>
    <groupId>org.mybatis.spring.boot</groupId>
    <artifactId>mybatis-spring-boot-starter</artifactId>
    <version>3.0.3</version> > </dependency>
```

### 📝 추가 설명: MyBatis 설정 및 매퍼 인터페이스
1. **매퍼 스캔**: MyBatis 매퍼 인터페이스가 위치한 패키지를 Spring Boot 애플리케이션에 알려줘야 합니다.
	- **가장 간단한 방법**: 매퍼 인터페이스에 `@Mapper` 어노테이션을 붙입니다.
	- **설정 파일 사용**: 메인 애플리케이션 클래스에 `@MapperScan("com.example.demo.dao")`를 추가할 수도 있습니다.
2. **`@Mapper`**** 인터페이스**:
	- 요청하신 `ArticleDao.java` 파일처럼 인터페이스에 `@Mapper` 어노테이션을 붙여 Spring에서 **DAO(Data Access Object)** 빈으로 등록되도록 합니다.

## 📄 `ArticleDao` 코드 적용 및 설명
요청하신 `ArticleDao` 인터페이스에 **SQL 매핑 어노테이션**을 적용하고, **변수 추가**에 대한 설명을 추가합니다.
### 🧩 `ArticleDao.java` 코드표 (예시)

| **메서드** | **SQL 어노테이션** | **SQL 내용 및 설명** |
| --- | --- | --- |
| `writeArticle` | `@Insert` | **제목**과 **내용**을 받아 새 게시글을 데이터베이스에 삽입합니다. |
| `showList` | (XML 매핑 또는 `@Select` 사용) | 전체 게시글 목록을 조회합니다. |
| `getArticleById` | (XML 매핑 또는 `@Select` 사용) | 특정 ID의 게시글 하나를 조회합니다. |
| `modifyArticle` | (XML 매핑 또는 `@Update` 사용) | 게시글을 수정합니다. (아래 동적 SQL 예시 참고) |
| `deleteArticle` | (XML 매핑 또는 `@Delete` 사용) | 특정 게시글을 삭제합니다. |

### `writeArticle` 적용 예시
Java
```java
// package, import 생략
@Mapper
public interface ArticleDao {
	
	@Insert("""
			INSERT INTO article (title, content, regDate, updateDate)
			VALUES (#{title}, #{content}, NOW(), NOW())
			""")
	// 메서드 인자로 SQL에 필요한 변수(title, content)를 받습니다.
	public void writeArticle(@Param("title") String title, @Param("content") String content);

    // ... 다른 메서드
}
```

> 📌 수량 증감 버튼 힌트:
	만약 게시글의 '좋아요' 수 등을 증감하는 버튼을 구현한다면, DAO에서는 UPDATE 쿼리를 사용하며 증감 연산자를 활용합니다.
	`UPDATE article SET hitCount = hitCount + 1 WHERE id = #{id}`
### 🔑 변수 추가: 인자, 매개변수, 파라미터 (줄 추가가 없을 때)
- **인자 (Argument)**: **메서드를 호출**할 때 전달하는 **실제 값**입니다. (예: `articleDao.writeArticle("제목", "내용");` 여기서 `"제목"`과 `"내용"`이 인자입니다.)
- **매개변수 (Parameter)**: **메서드 정의**에서 인자를 받아들이는 **변수**입니다. (예: `public void writeArticle(String title, String content)` 여기서 `title`과 `content`가 매개변수입니다.)
- **`@Param`**: MyBatis에서 **매개변수가 2개 이상**이거나 SQL에서 **명시적인 이름**으로 매개변수를 사용하고 싶을 때 사용합니다. `@Param("title")`을 붙이면 SQL 내에서 `#{title}`로 해당 변수에 접근할 수 있습니다.

## 🔄 MyBatis 동적 SQL 및 게시글 수정 (Update)
**동적 SQL**은 조건에 따라 SQL 문장을 다르게 구성할 수 있게 해주는 MyBatis의 강력한 기능입니다.
### 동적 SQL 읽어보기
요청하신 게시글 수정(Update) 예시는 **`<script>`** 태그와 **`<if>`** 태그를 활용한 동적 SQL의 대표적인 예입니다.
### 마이바티스로 게시글 한 가지만 수정하기 예시 (수정 및 설명 추가)
Java
```java
// ArticleDao.java 내
@Update("""
        <script>
        UPDATE article
            SET updateDate = NOW()
            <if test="title != null and title != ''">	
                , title = #{title}
            </if>
            <if test="content != null and content != ''">	
                , content = #{content}  </if>
        WHERE id = #{id}
        </script>
        """)
// 매개변수가 2개 이상이므로 @Param 사용을 권장하며, Article 객체를 활용할 수도 있습니다.
public void modifyArticle(@Param("id") int id, @Param("title") String title, @Param("content") String content);
// 요청하신 원본에는 where id = #{id}가 content 조건 안에 있었지만, 수정했습니다.

// 요청하신 원본 메서드 시그니처: 
// public void modifyArticle(Article article, String title, String content);
// 이 시그니처를 사용하려면 Article 객체 내의 필드(id)와 별도의 title/content를 조합해 사용해야 합니다.
```

- **`<script>`**: 동적 SQL 작성을 허용합니다.
- **`<if test="...">`**: `test` 조건이 \*\*참(true)\*\*일 경우 해당 SQL 조각을 삽입합니다.
	- `title != null and title != ''`: `title` 값이 null이 아니고 비어있지 않은 경우에만 `, title = #{title}`을 추가합니다.
- **`SET updateDate = NOW()`**: 수정할 내용이 없어도 `updateDate`는 현재 시각으로 갱신되도록 합니다.
- **`WHERE id = #{id}`**: 수정할 게시글을 특정합니다.

## 💻 JSP 관련 기술 (Model, EL, JSTL, 스크립틀릿)
웹 화면 구성(View)에 사용되는 기술들입니다.
### **Model 객체 (Spring MVC)**

| **개념** | **설명** |
| --- | --- |
| **Model 객체** | Controller에서 View(JSP 등)로 데이터를 전달하는 데 사용되는 객체입니다. Spring MVC에서 **데이터를 담는 저장소** 역할을 합니다. |
| **예시** | Controller에서 `model.addAttribute("articleList", list);` 와 같이 데이터를 담으면, View에서 해당 이름(`articleList`)으로 접근할 수 있습니다. |

### **EL 표기법 (Expression Language)**

| **개념** | **설명** |
| --- | --- |
| **EL 표기** | JSP에서 **Model에 저장된 속성 값**이나 **자바 객체의 속성 값**을 출력할 때 사용하는 간결한 표현식입니다. |
| **형식** | `${속성명}` |
| **예시** | `model.addAttribute("title", "환영합니다");`를 JSP에서 출력: **`${title}`** -\> 출력 결과: `환영합니다` |

### **JSTL (JSP Standard Tag Library)**

| **개념** | **설명** |
| --- | --- |
| **JSTL** | JSP에서 \*\*자바 문법(반복문, 조건문 등)\*\*의 활용을 **XML 기반의 태그** 형태로 제공하여 스크립틀릿 사용을 지양하고 **View와 로직을 분리**하는 데 도움을 줍니다. |
| **설명** | `-> 자바 문법 활용 비슷한 느낌` |
| **예시 태그** | `<c:forEach>` (반복), `<c:if>` (조건) 등. |

### JSTL 구현 (impl) 및 선언
Java
`<%@ taglib uri="http://java.sun.com/jsp/jstl/core" prefix="c" %>`
- JSP 파일 상단에 이 코드를 추가하여 **`<c:>`** 접두사로 JSTL의 핵심(core) 라이브러리 태그를 사용할 수 있게 선언합니다.
- **JSTL 라이브러리**(`.jar`)가 프로젝트에 추가되어 있어야 정상 작동합니다.
### **스크립틀릿 (Scriptlet)**

| **개념** | **설명** |
| --- | --- |
| **스크립틀릿** | JSP 파일 내에서 **`<%, <%=, %>`** 기호를 사용하여 **자바 코드**를 직접 작성하는 방식입니다. |
| **설명** | `-> 자바 문법 활용, 화면에 구성하는 것` |
| **현황** | **MVC 패턴**에서 View의 역할만 해야 하는 JSP에 로직이 섞이는 것을 방지하기 위해 **현대적인 개발에서는 사용이 권장되지 않습니다.** |
