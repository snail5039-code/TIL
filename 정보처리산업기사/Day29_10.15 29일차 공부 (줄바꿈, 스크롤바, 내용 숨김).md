## 1. 문자 디테일 처리
이 단락에서는 텍스트의 **줄바꿈 처리**와 **넘침 처리**에 사용되는 핵심 CSS 속성들을 다룹니다.

| 속성 | 값 | 설명 |
| --- | --- | --- |
| `white-space` | `nowrap` | **줄바꿈 금지**. 내용이 부모 요소를 넘어가더라도 한 줄에 표시합니다. |
| `white-space` | `wrap` | **줄바꿈 허용**. 기본값이며, 내용이 부모 요소를 넘치면 자동으로 줄바꿈됩니다. |
| `overflow` | `hidden` | **넘친 내용 숨기기**. 부모 요소의 영역을 벗어나는 내용을 잘라내고 숨깁니다. |
| `overflow` | `scroll` | **스크롤바 무조건 생성**. 내용이 넘치든 안 넘치든 스크롤바를 항상 표시합니다. (`overflow-x`, `overflow-y`로 방향 지정 가능) |
| `overflow` | `auto` | **스크롤바 자동 생성/제거**. 내용이 넘칠 때만 스크롤바가 자동으로 생성되고, 넘치지 않으면 사라집니다. |
| `text-overflow` | `ellipsis` | **넘친 텍스트 줄임표 처리**. `white-space: nowrap;` 및 `overflow: hidden;`과 함께 사용하여, 숨겨진 텍스트를 `...`으로 표시합니다. |
| `position` | `fixed` | **고정 위치**. 화면 스크롤에 관계없이 요소가 항상 같은 위치에 고정됩니다. (예: 바로가기 버튼) |

## 2. 줄바꿈 제어 및 넘침 처리 예시
### A. 줄바꿈 금지 (`white-space: nowrap;`)
텍스트가 부모 요소의 너비를 초과하더라도 강제로 줄바꿈을 하지 않고 한 줄로 표시합니다.
HTML

```html
<div>
  Lorem, ipsum dolor sit amet consectetur adipisicing elit. Cupiditate veniam cum, corrupti praesentium sit, atque ad optio inventore omnis quod nostrum amet eveniet? Assumenda labore accusamus soluta adipisci, aliquam veniam?
</div>
```
CSS
```css
div {
  padding:10px;
  font-size:2rem;
  width:1000px;
  margin:0 auto;
  background-color:red;
  /* 절대 줄바꿈 금지 */
  white-space:nowrap;
}
```

### B. 가로 스크롤바 자동 생성 (`overflow-x: auto;`)
`white-space: nowrap;`으로 줄바꿈을 금지한 상태에서, 내용이 넘칠 경우에만 가로 방향으로 스크롤바가 자동 생성됩니다.
HTML
```html
<div>
  Lorem, ipsum dolor sit amet consectetur adipisicing elit. Cupiditate veniam cum, corrupti praesentium sit, atque ad optio inventore omnis quod nostrum amet eveniet? Assumenda labore accusamus soluta adipisci, aliquam veniam?
</div>
```
CSS
```css
div {
  padding:10px;
  font-size:2rem;
  width:1000px;
  margin:0 auto;
  background-color:red;
  white-space:nowrap;
  /* 가로방향으로 스크롤바를 무조건 생성(넘치치 않으면 스크롤바가 안생김) */
  overflow-x:auto;
}
```
### C. 가로 스크롤바 무조건 생성 (`overflow-x: scroll;`)
내용의 넘침 여부와 관계없이 가로 방향 스크롤바를 항상 표시합니다.
HTML
```html
<div>
  내용
</div>
```
CSS
```css
div {
  padding:10px;
  font-size:2rem;
  width:1000px;
  margin:0 auto;
  background-color:red;
  white-space:nowrap;
  /* 필요에 따라 가로 스크롤바 생성 */
  overflow-x:scroll;
}
```
### D. 넘치는 내용 숨김 및 줄임표 처리 (`overflow: hidden;`, `text-overflow: ellipsis;`)
내용을 한 줄로 표시(`white-space: nowrap;`)하고, 부모 요소를 넘어가는 부분을 숨긴(`overflow-x: hidden;`) 후, 숨겨진 텍스트를 줄임표(`...`)로 대체하여 표시합니다.
HTML
```html
<div>
  Lorem ipsum dolor sit amet, consectetur adipisicing elit. Totam ratione expedita voluptatem tenetur saepe consectetur numquam quas enim molestias, dolorem ex. Labore mollitia magnam architecto laborum fugit ut, illo animi?
</div>
```
CSS
```css
div {
  padding:10px;
  font-size:2rem;
  width:1000px;
  margin:0 auto;
  background-color:red;
  white-space:nowrap;
  /* 넘쳐나는 내용 무조건 숨김 */
  overflow-x:hidden;
  /* 넘친 텍스트 ... 으로 처리 */
  text-overflow:ellipsis;
}
```

## 3. 고정 위치 요소 (`position: fixed;`)
요소가 뷰포트(화면)를 기준으로 고정되어, 스크롤을 움직여도 요소는 항상 같은 위치에 머무르게 합니다. (예: 상단 네비게이션바 또는 바로가기 버튼)
CSS
```css
n.fixed-button {
    position: fixed;
    bottom: 20px;
    right: 20px;
    }
```

| 설명 |
| --- |
| 화면의 오른쪽 하단(뷰포트 기준)에 요소를 고정합니다. |
