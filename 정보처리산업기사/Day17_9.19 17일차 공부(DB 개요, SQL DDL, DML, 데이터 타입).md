### **데이터베이스(DB)의 기본 개념** 💾
데이터베이스는 데이터를 체계적으로 저장하고 관리하는 시스템이에요. **DB(DataBase)** 는 말 그대로 **데이터 저장소**를 의미하고, 이 데이터를 효율적으로 관리하기 위한 프로그램이 바로 **DBMS(DataBase Management System)** 입니다. DBMS를 조작하려면 **SQL(Structured Query Language)** 이라는 언어가 필요해요. SQL은 DBMS의 종류에 따라 문법이 조금씩 다르지만, **표준 SQL**을 기반으로 하기 때문에 대부분의 문법은 9:1 비율로 유사해요.
- **DB 서버**: 사용자의 요청에 응답하여 데이터를 제공하는 프로그램.
- **클라이언트**: DB 서버에 접속하여 요청을 보내는 프로그램.

| **DB 서버 종류** | **DBMS 클라이언트 종류** | **특징** |
| --- | --- | --- |
| Oracle | Oracle | 대규모 엔터프라이즈 환경에 적합, 유료 |
| MySQL | MySQL | 오픈 소스, 가볍고 속도가 빠름, 웹 개발에 많이 사용 |
| MSSQL | MSSQL | Microsoft 제품, 윈도우 환경에 최적화 |
| PostgreSQL | PostgreSQL | 객체-관계형 DB, 기능이 풍부하고 확장성이 좋음 |

### **RDBMS: 관계형 데이터베이스** 🔗
웹 개발에서 거의 99% 사용하는 **RDBMS(Relational DataBase Management System)** 는 데이터들이 관계를 형성하고 있는 형태로 데이터를 처리해요.<br>데이터는 **테이블(Table)** 이라는 표 형태로 저장되며, 이 테이블은 자바의 `Class`와 비슷한 개념으로 볼 수 있어요.
### **RDBMS의 구성 요소**
- **스키마(Schema)**: 테이블을 만들기 위한 구조와 제약을 명세하는 것.
- **테이블(Table)**: 행(Row)과 열(Column)로 구성된 2차원 표.
- **행(Row)**: **튜플(Tuple)** 또는 **레코드(Record)** 라고도 불리며, 하나의 개체에 대한 모든 정보를 담고 있어요.
	- *예: 홍길동(이름), 25(나이), 대전(거주지)*
- **열(Column)**: **어트리뷰트(Attribute)** 또는 **필드(Field)** 라고도 불리며, 모든 개체에 대한 특정 속성을 나타내요.
	- *예: 모든 학생의 나이(25, 22...)*

### **SQL 명령어의 분류** 🏷️
SQL은 크게 네 가지 언어 그룹으로 나눌 수 있어요.
- **DDL (Data Definition Language)**: **데이터 정의 언어**. 데이터베이스의 구조를 정의하는 명령어로, 데이터베이스 엔지니어나 관리자가 주로 사용해요.
	- `CREATE`: DB, 테이블 생성
	- `DROP`: DB, 테이블 삭제
	- `ALTER`: DB, 테이블 수정
	- `SHOW`: 구조 조회
- **DML (Data Manipulation Language)**: **데이터 조작 언어**. 데이터를 조작하는 명령어로, 개발자나 데이터 분석가가 많이 사용해요.
	- `INSERT`: 데이터 추가
	- `SELECT`: 데이터 조회
	- `UPDATE`: 데이터 수정
	- `DELETE`: 데이터 삭제
- **DCL (Data Control Language)**: **데이터 제어 언어**. 계정 관리, 권한 부여 등 DB 서버를 제어하는 명령어.
- **TCL (Transaction Control Language)**: **트랜잭션 제어 언어**. 트랜잭션(여러 개의 작업이 하나의 단위로 묶인 것)을 제어하는 명령어.
	- `COMMIT`: 변경 사항 확정
	- `ROLLBACK`: 변경 사항 취소

### **실행 명령어 예시** 💻
아래는 DDL과 DML의 구체적인 명령어 예시들이에요.
### **DDL (데이터베이스 및 테이블 관리)**
- `CREATE DATABASE [데이터베이스 이름];` : 데이터베이스 생성
- `USE [데이터베이스 이름];` : 사용할 데이터베이스 선택
- `CREATE TABLE article(...)` : `article` 테이블 생성
- `DESC article;` : `article` 테이블의 구조 확인
- `DROP TABLE article;` : `article` 테이블 삭제
### **DML (데이터 조작)**

| **기능** | **명령어 예시** | **설명** |
| --- | --- | --- |
| **추가** | `INSERT INTO article SET title = '제목1', body = '내용1';` | 컬럼을 지정하여 데이터 추가 |
| **추가** | `INSERT INTO article (title, body) VALUES ('제목2', '내용2');` | 컬럼과 값의 순서를 맞춰서 데이터 추가 |
| **수정** | `UPDATE article SET title = '제목12' WHERE body = '내용3';` | `body`가 '내용3'인 행의 `title`을 '제목12'로 수정 |
| **삭제** | `DELETE FROM article WHERE body = '내용3';` | `body`가 '내용3'인 행 삭제 |
| **조회** | `SELECT * FROM article;` | `article` 테이블의 모든 데이터 조회 |

### **주요 데이터 타입** 📝
데이터베이스에서 테이블을 만들 때, 각 컬럼에 어떤 종류의 데이터가 들어갈지 **데이터 타입**과 **제약사항**을 설정해야 합니다. 자주 사용되는 데이터 타입은 다음과 같습니다.

| 분류 | 데이터 타입 | 설명 | 예시 |
| --- | --- | --- | --- |
| **문자열** | `CHAR(n)` | **고정 길이 문자열**. `n`으로 지정된 크기만큼 메모리를 항상 사용합니다. 저장되는 데이터의 길이가 고정적일 때 (예: 우편번호, 성별 등) 효율적입니다. | `CHAR(10)`: 'A'를 저장해도 10바이트를 차지 |
|  | `VARCHAR(n)` | **가변 길이 문자열**. 데이터의 실제 길이에 맞게 메모리를 사용하며, 지정된 최대 크기까지만 저장할 수 있습니다. 텍스트 데이터의 길이가 다양할 때 주로 사용됩니다. | `VARCHAR(10)`: 'Hello'를 저장하면 5바이트 + α(길이 정보) |
|  | `TEXT` | `VARCHAR`보다 더 큰 용량의 긴 텍스트를 저장할 때 사용됩니다. | `TEXT`: 블로그 게시글의 본문 |
| **숫자** | `INT` | 정수를 저장합니다. | `INT`: 나이, 수량 |
|  | `DECIMAL(p, s)` | 정밀한 숫자를 저장합니다. `p`는 전체 자릿수, `s`는 소수점 이하 자릿수입니다. 금융 데이터와 같이 정확한 계산이 필요한 경우에 사용됩니다. | `DECIMAL(5, 2)`: 최대 999.99까지 저장 가능 |
| **날짜/시간** | `DATE` | 날짜(YYYY-MM-DD)를 저장합니다. | `DATE`: '2023-10-26' |
|  | `TIME` | 시간(HH:MM:SS)을 저장합니다. | `TIME`: '15:30:00' |
|  | `DATETIME` | 날짜와 시간(YYYY-MM-DD HH:MM:SS)을 함께 저장합니다. | `DATETIME`: '2023-10-26 15:30:00' |
| **기타** | `JSON` | JSON 형식의 데이터를 저장합니다. 복잡한 구조의 데이터를 한 필드에 저장할 때 유용합니다. | `JSON`: `{"name": "홍길동", "age": 25}` |

기본 문제 풀이
```sql
# 전체 데이터베이스 리스팅
SHOW DATABASES;

# `mysql` 데이터 베이스 선택
USE mysql;

# 테이블 리스팅
SHOW TABLES;

# `db` 테이블의 구조 확인
DESC db;
DESCRIBE db;

# 기존에 `board` 데이터베이스가 존재 한다면 삭제
DROP DATABASE IF EXISTS board;

# 새 데이터베이스(`board`) 생성
CREATE DATABASE board;

# 데이터베이스 추가 되었는지 확인
SHOW DATABASES;

# `board` 데이터 베이스 선택
USE board;

# 테이블 확인
SHOW TABLES;

# 게시물 테이블(`article`)을 만듭니다.
CREATE TABLE article(
        title VARCHAR(100)
        , `body` TEXT
);

# 잘 추가되었는지 확인
SHOW TABLES;

# 제목은 '제목1', 내용은 '내용1'인 데이터 하나 추가 
INSERT INTO article
    SET title= '제목1'
        ,`body` = '내용1';
        
# 제목 조회
SELECT title FROM article; 


# 내용 조회
SELECT `body` FROM article; 

# 제목, 내용 칼럼 데이터 조회
SELECT title,`body` FROM article; 

# 내용, 제목 칼럼 데이터 조회
SELECT `body`, title FROM article; 

# 모든 데이터 조회
SELECT * FROM article;

# 제목1, 내용1 데이터 추가
INSERT INTO article
    SET title = '제목1'
        ,`body` = '내용1';

# 제목2, 내용2 데이터 추가
INSERT INTO article
    SET title = '제목2'
        ,`body` = '내용2';

# 데이터 조회
SELECT * FROM article;

# 제목 데이터 aaa로 수정(모두 수정됨..)
UPDATE article
    SET title = 'aaa';

# `body`가 내용2인 것만 조회
SELECT `body` FROM article
    WHERE `body` = '내용2';
    
SELECT * 
    FROM article
    WHERE `body` = '내용2';  
    

# 내용2만 새로운내용2 로 수정
UPDATE article
    SET `body` = '새로운내용2'
    WHERE `body` = '내용2';

# 데이터 조회
SELECT * FROM article;

# 데이터 삭제 (모든 데이터가 삭제...)
DELETE FROM article;

# 다시 

# 제목1, 내용1 데이터 추가
INSERT INTO article
    SET title = '제목1'
        ,`body` = '내용1';
        
# 제목2, 내용2 데이터 추가
INSERT INTO article
    SET title = '제목2'
        ,`body` = '내용2';

# 제목이 제목1인 것만 삭제
DELETE FROM article
    WHERE title = '제목1';
```
