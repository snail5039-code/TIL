## 1. ⚙️ 동기(Synchronous) 방식 통신
**동기 방식**은 지금까지 흔히 사용해 오던 통신 방식으로, 작업들이 **순서대로** 처리됩니다.
- **특징:**
	- **A** 작업이 **완전히 끝날 때까지** **B** 작업은 **대기**해야 합니다.
	- 이전 작업의 완료가 다음 작업의 시작 조건이 됩니다.
	- 전통적인 웹 페이지의 **새로고침**이나 일반적인 **링크(\<a\>)**, **버튼 클릭**으로 페이지를 이동하는 방식이 동기 통신의 예시입니다.
	- 만약 A 작업에서 서버 응답이 오래 걸린다면, 사용자는 그 시간 동안 웹 페이지에서 **아무것도 할 수 없고** 기다려야 합니다.

---

## 2. 🚀 비동기(Asynchronous) 방식 통신
**비동기 방식**은 작업의 완료를 기다리지 않고 **동시에 여러 작업을 처리**할 수 있는 통신 방식입니다.
- **특징:**
	- **A** 작업이 진행되는 동안, **B** 작업도 **별도로 시작**될 수 있습니다. 즉, A 작업의 완료를 기다리지 않습니다.
	- 전통적인 **새로고침 없이** 화면의 일부만 업데이트하거나 데이터를 가져올 수 있습니다.
	- 서버에서 데이터를 요청해오는 동안에도 사용자는 웹 페이지의 다른 부분을 조작하거나 볼 수 있어 **사용자 경험(UX)이 향상**됩니다.
	- 비동기 작업의 결과는 주로 **콜백 함수**를 통해 처리됩니다.
- **비동기 통신 기술:**
	- **Ajax (Asynchronous JavaScript and XML):** 제이쿼리(jQuery) 라이브러리를 통해 쉽게 구현할 수 있습니다.
	- **Fetch API:** 최신 JavaScript(바닐라 JS)에서 기본적으로 제공하는 비동기 통신 기능입니다.
	- **XMLHttpRequest (XHR):** 바닐라 JS에서 제공하는 전통적인 비동기 통신 객체입니다.

---

## 3. 🌐 Ajax의 역할
**Ajax**는 **Asynchronous JavaScript and XML**의 약자로, JavaScript를 사용하여 웹 서버와 데이터를 교환하고 웹 페이지 전체를 새로고침하지 않고도 **화면의 일부만을 갱신**할 수 있게 해주는 기술입니다.
- **핵심 역할:** 웹 애플리케이션의 **반응성**과 **대화형 기능**을 크게 향상시킵니다. (예: 페이지 이동 없이 실시간 댓글 달기, 검색 자동 완성 기능 등)

---

## 4. 📝 비동기 방식의 사용법 및 예시
비동기 방식은 주로 **데이터를 가져오거나(GET)**, \*\*전송(POST)\*\*할 때 사용되며, 결과는 **콜백 함수**나 **Promise**를 통해 처리됩니다.
### **콜백 함수를 사용한 처리**
가장 기본적인 비동기 처리 방법은 **콜백 함수**를 사용하는 것입니다. 비동기 작업이 **완료되면 호출**되도록 예약된 함수를 콜백 함수라고 합니다.
- **예시: ****`setTimeout()`**** 함수**JavaScript
	`setTimeout()`은 지정된 시간이 지난 후 콜백 함수를 실행하는 **비동기 함수**입니다.
	
	```java
console.log("1. 작업 시작");

// 2초 후에 실행될 비동기 작업 (콜백 함수)
setTimeout(function() {
    console.log("2. 서버에서 데이터 로딩 완료"); // 2초 후 실행
}, 2000); // 2000ms = 2초

console.log("3. 다음 작업 바로 진행"); // 1번 실행 후 바로 실행됨
	```
	- **결과 순서:** **1. 작업 시작** \$\\rightarrow\$ **3. 다음 작업 바로 진행** \$\\rightarrow\$ (2초 후) \$\\rightarrow\$ **2. 서버에서 데이터 로딩 완료**
	- `setTimeout` 함수는 2초를 기다리지 않고 바로 다음 코드인 `console.log("3...")`를 실행(비동기)합니다. 2초 후 콜백 함수가 실행됩니다.
### **Fetch API (Promise 기반)를 사용한 예시**
최근에는 **Fetch API**나 \*\*Ajax(jQuery)\*\*를 사용하여 서버에서 데이터를 가져올 때 Promise라는 것을 활용하여 비동기 작업의 결과를 더 체계적으로 처리합니다.
- **예시: 외부 API에서 사용자 데이터 가져오기**JavaScript
	
	```java
fetch('https://jsonplaceholder.typicode.com/users/1') // 비동기로 데이터 요청 시작
  .then(response => response.json()) // 응답이 오면 JSON 형태로 파싱 (Promise)
  .then(data => {
    // 실제 데이터가 파싱되면 실행되는 콜백 함수
    console.log("사용자 이름:", data.name);
  })
  .catch(error => {
    // 요청 실패 시 실행되는 콜백 함수
    console.error("데이터 가져오기 실패:", error);
  });

console.log("Fetch 요청 후, 다음 코드가 바로 실행됩니다.");
	```
	- `fetch()`를 호출하면 **즉시** 다음 줄(`console.log(...)`)이 실행되고, 서버에서 데이터를 가져오는 작업은 **백그라운드**에서 비동기로 진행됩니다.
	- 데이터가 성공적으로 도착하면 `.then()` 내부의 함수가 실행되어 화면을 업데이트하는 등의 작업을 수행합니다.
