### 1. 📂 게시판 분리 및 아키텍처
### **MyBatis 기반의 아키텍처 (Service/DAO 역할)**
- **현재 구현:** DTO를 사용하지 않고 MyBatis를 통해 **Controller**에서 직접 변수를 선언하여 게시판 분리 및 페이징 처리를 했다고 하셨습니다. 이는 **간단한** 프로젝트에서는 가능하지만, **유지보수성**과 **확장성**을 위해 **Service Layer**와 **DAO Layer**를 분리하는 것이 일반적이고 권장됩니다.
- **권장 아키텍처:**
	- **DAO (Data Access Object) / Mapper:** MyBatis를 사용하여 데이터베이스 접근(CRUD)만을 담당합니다. SQL 매핑과 실행을 전담합니다.
	- **Service:** 비즈니스 로직(예: 게시글 작성, 수정, 페이징 계산, 트랜잭션 처리 등)을 담당합니다. 여러 DAO를 조합하여 복잡한 작업을 처리할 수도 있습니다.
	- **Controller:** HTTP 요청을 받고 응답하는 역할만 담당합니다. Service 계층을 호출하여 비즈니스 로직을 실행합니다.
- **요청하신 상황 가정:**
	- "서비스, dao를 아티클 컨트롤러에 만든다고 가정했을 때 보드 서비스를 아티클 컨트롤러에 의존성 주입을 한다."
	- 이는 아키텍처적으로 **비권장**되지만, 가정하신 대로라면 `BoardService`의 역할을 하는 컴포넌트를 만들고 이를 `ArticleController`에 \*\*의존성 주입(DI)\*\*하여 비즈니스 로직을 처리해야 합니다.

### 2. 📝 게시판 선택 및 데이터 전달
### **글쓰기 시 게시판 선택 (Input / Data)**
- **사용자 입력:** 글을 작성할 때 게시판을 선택할 수 있도록 `<input type="radio">`나 `<select>` 태그를 사용하여 구현합니다.
- **데이터 전달 (Name/Value):**
	- `name` 속성은 폼 데이터가 서버로 전송될 때 **변수 이름**으로 사용됩니다. (예: `boardId`)
	- `value` 속성은 해당 필드의 **실제 값**으로 서버에 전달됩니다. (예: `1`은 자유 게시판, `2`는 공지 게시판 등)
	- "네임으로만 넘어가서 벨류를 쓸 수 있다."는 표현은 `name`으로 설정된 변수 이름으로 `value`에 담긴 값이 서버(Controller)로 전달된다는 의미로 해석됩니다.
- **스크립트 사용 (ID):**
	- `id` 속성은 주로 **JavaScript/jQuery**와 같은 클라이언트 측 스크립트에서 특정 HTML 요소를 선택하고 조작하기 위해 사용됩니다.
	- "id는 스크립트에서 쓸 수 있다."

### 3. 🔢 페이징 처리 로직
### **SQL LIMIT/OFFSET을 이용한 데이터 조회**
- **페이지당 게시글 수:** `10개`로 가정합니다.
- **데이터 조회 시작 지점 (Offset):**
	- 클릭한 페이지 번호가 \$P\$일 때, \$P\$ 페이지의 첫 번째 게시글은 전체 목록에서 \$(P-1) \\times 10\$ 번째입니다.
	- **SQL ****`LIMIT`**** 절 (MySQL 기준):** `LIMIT 10 OFFSET (클릭한 페이지 - 1) * 10`
	- "(x-1) \* 10" 이 바로 데이터베이스에서 조회할 시작 인덱스(Offset)를 계산하는 핵심 공식입니다.
### **페이지 그룹핑 (페이지 밑단 10개씩)**
- **목표:** 페이지 번호를 1, 2, ..., 10 / 11, 12, ..., 20 / ... 와 같이 **10개씩** 그룹 지어 표시합니다.
- **변수:**
	- `currentPage`: 현재 사용자가 클릭한 페이지 번호 (예: 15)
	- `pageSize`: 한 화면에 보여줄 페이지 번호의 개수 (예: 10)
- **시작 페이지 (****`startPage`****) 계산:**
	- 공식: \$\\lfloor \\frac\{\\text\{currentPage\} - 1\}\{\\text\{pageSize\}\} \\rfloor \\times \\text\{pageSize\} + 1\$
	- 요청하신 코드: `(현재 페이지 - 1) / 10) * 10 + 1`
- **끝 페이지 (****`endPage`****) 계산:**
	- 공식: \$\\lfloor \\frac\{\\text\{currentPage\} - 1\}\{\\text\{pageSize\}\} \\rfloor \\times \\text\{pageSize\} + \\text\{pageSize\}\$
	- 요청하신 코드: `(현재 페이지 - 1) /10) +1 * 10` (이 공식은 괄호가 빠져서 오해의 소지가 있습니다.) **올바른 공식은 아래 예시 참고.**
### **코드 예시 (Java 또는 유사 언어)**
Java
```java
// 페이지 관련 변수
int currentPage = 15; // 현재 페이지
int pageSize = 10;    // 한 화면에 보여줄 페이지 번호 개수 (예: 10개)
int totalCount = 1000; // 전체 게시글 수 (DAO에서 조회)

// 1. 총 페이지 수 계산 (Total Page Count)
// 예를 들어, 페이지당 게시글 수가 10개라면:
int totalPages = (int) Math.ceil((double) totalCount / pageSize); // 1000 / 10 = 100 페이지

// 2. 시작 페이지 (Start Page) 계산
// 15페이지를 클릭했을 때: ((15 - 1) / 10) * 10 + 1 => (1) * 10 + 1 => 11
int startPage = ((currentPage - 1) / pageSize) * pageSize + 1;

// 3. 끝 페이지 (End Page) 계산
// 15페이지를 클릭했을 때: 11 + 10 - 1 = 20
int endPage = startPage + pageSize - 1;

// **중요:** 계산된 끝 페이지가 실제 총 페이지 수를 초과하면 안 됩니다.
if (endPage > totalPages) {
    endPage = totalPages; // 총 페이지 수로 제한
}

// 결과 (15페이지 클릭 시):
// startPage = 11
// endPage = 20
```

- **반복문 사용:** 위에서 계산된 `startPage`와 `endPage`를 사용하여 JSTL이나 Thymeleaf 같은 템플릿 엔진의 반복문 (`for` loop)으로 페이지 번호를 출력합니다.
