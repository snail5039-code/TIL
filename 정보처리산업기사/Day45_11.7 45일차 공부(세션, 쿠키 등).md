### 🌐 HTTP (HyperText Transfer Protocol)
HTTP는 웹에서 데이터를 주고받는 데 사용되는 프로토콜입니다.
- **비연결 프로토콜 (Stateless Protocol)**: HTTP의 가장 큰 특징은 **비연결성**입니다. 클라이언트(브라우저)가 서버에 요청(Request)을 보내고 서버가 응답(Response)을 보내면 연결이 끊어지며, 서버는 클라이언트의 이전 상태(state)를 기억하지 못합니다.
- **문제점 및 해결**: 웹 페이지를 탐색하는 동안 사용자 로그인 상태나 장바구니 내용 등 **사용자 상태를 유지**해야 할 필요가 생깁니다. 이를 위해 \*\*세션(Session)\*\*과 **쿠키(Cookie)** 같은 기술을 사용하여 상태를 관리합니다.

---

### 💾 세션 (Session)
**세션**은 웹사이트에서 **사용자의 상태 데이터를 저장하는 공간**입니다.
- **저장 위치**: 데이터는 **서버 측**에 저장됩니다. 이는 쿠키에 비해 상대적으로 **보안성이 높습니다.**
- **생성 및 관리**:
	- 사용자가 웹사이트에 접속하면 서버는 해당 사용자를 위한 **세션 객체**를 생성합니다.
	- 이때, 서버는 클라이언트의 브라우저에 **세션 ID**를 담은 **쿠키**를 전송합니다. 이 세션 ID를 보통 **`JSESSIONID`** (Java EE 환경 기준)라고 부릅니다.
	- 이후 클라이언트가 서버에 요청을 보낼 때마다 이 세션 ID 쿠키를 함께 전송하며, 서버는 이 ID를 이용해 해당 사용자의 상태 데이터를 불러옵니다.
- **예제 코드 (JSP/Servlet 환경)**:Java
	
```java
<%
    // 세션에 데이터 저장
    session.setAttribute("userID", "gemini123"); 

    // 세션에서 데이터 가져오기
    String userId = (String) session.getAttribute("userID");
%>
<p>현재 로그인된 사용자 ID: <%= userId %></p>
```

### 🍪 쿠키 (Cookie)
**쿠키**는 **웹사이트에 접속할 때 생성되는 데이터를 저장하는 임시 파일**입니다.
- **저장 위치**: 데이터는 **클라이언트(브라우저)** 측에 저장됩니다.
- **사용 목적**: 사용자 ID 저장, 팝업 '오늘 하루 안 보기' 설정, 사용자 선호 설정 등 **상태 정보**를 클라이언트에 저장하여 서버 부하를 줄이고 사용자 편의성을 높입니다.
- **보안**: 클라이언트 측에 저장되므로, 세션 데이터보다 **보안에 취약**할 수 있습니다.
- **예제 코드 (JSP/Servlet 환경)**:Java
	
```java
// 쿠키 생성 및 클라이언트에 전송 (서버 코드)
Cookie userCookie = new Cookie("lastVisit", new Date().toString());
userCookie.setMaxAge(60 * 60 * 24 * 7); // 7일 동안 유지
response.addCookie(userCookie);
```

### ❓ `onblur=""`
`onblur`는 HTML의 **이벤트 핸들러** 속성 중 하나로, 주로 **폼(Form) 요소**에서 사용됩니다.
- **역할**: 해당 요소가 **포커스(Focus)를 잃었을 때** 실행할 자바스크립트 코드를 지정합니다.
- **주요 사용처**: 사용자가 폼 입력란(예: 텍스트 상자)에서 입력을 마친 후 다른 곳을 클릭하거나 탭 키를 눌러 포커스가 이동될 때, 입력된 값의 유효성 검사(Validation)를 수행하는 데 유용합니다.
- **예제 코드**:HTML
```html
<input type="text" id="username" onblur="validateUsername(this.value);">

<script>
    function validateUsername(username) {
        if (username.length < 5) {
            alert("사용자 이름은 5자 이상이어야 합니다.");
        }
    }
</script>
```

### 🚀 EL 내장 객체 (Expression Language Implicit Objects)
- \*EL (표현 언어)\*\*은 JSP에서 **데이터에 쉽게 접근**할 수 있도록 해주는 기술입니다. **EL 내장 객체**는 JSP 페이지에서 별도의 선언 없이 바로 사용할 수 있는 특정 범위의 데이터들을 가리킵니다.
- **주요 객체**:
	- `param`: 요청 파라미터 값에 접근 (예: `$\{param.username\}`)
	- `header`: HTTP 헤더 값에 접근
	- `cookie`: 쿠키 객체에 접근
	- `pageContext`: PageContext 객체에 접근
	- `sessionScope`: 세션 영역에 저장된 속성에 접근 (예: `$\{sessionScope.userID\}`)
	- `requestScope`, `applicationScope`, `pageScope`: 다른 범위에 저장된 속성에 접근
- **예제 코드 (JSP 환경)**:Java
```html
<p>요청 파라미터 ID: ${param.id}</p>

<p>현재 세션 사용자: ${sessionScope.userID}</p>
```

### 🛠️ `<c:if test>` (JSTL Core Tag)
`<c:if>`는 \*\*JSP Standard Tag Library (JSTL)\*\*의 **Core 라이브러리**에 속하는 태그로, **조건문** 역할을 합니다.
- **역할**: `test` 속성에 지정된 **EL 표현식**의 결과가 \*\*`true`\*일 때만 태그 내부의 내용을 \*\*실행(출력)\*\*합니다.
- **특징**: JSP 스크립트릿(`<% %>`) 대신 사용하여 코드를 간결하고 가독성 있게 만듭니다.
- **예제 코드 (JSP 환경)**:Java
	
```html
<%@ taglib prefix="c" uri="http://java.sun.com/jsp/jstl/core" %>

<c:set var="score" value="85" />

<c:if test="${score >= 90}">
    <p>A 등급입니다.</p>
</c:if>
<c:if test="${score >= 80 and score < 90}">
    <p>B 등급입니다.</p>
</c:if>
```
