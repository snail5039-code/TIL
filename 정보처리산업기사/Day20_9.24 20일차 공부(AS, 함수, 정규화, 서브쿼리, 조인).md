### 1. `AS` (별명)
- **기능**: 컬럼명, 테이블, 서브쿼리에 별명(Alias)을 지정합니다.
- **사용법**:
	- `SELECT id AS '번호' FROM article;`
	- `AS`는 생략 가능합니다: `SELECT id '번호' FROM article;`
- **주의사항**:
	- 컬럼명에 별명을 지을 때는 백틱(` `)을 사용합니다.
	- 테이블명에 별명을 지을 때는 백틱을 사용하지 않는 것이 좋습니다.
- **예시**:
	- **테이블 별명**: `SELECT id AS '번호' FROM article AS a;`
	- **컬럼 별명**: `SELECT id AS '번호' FROM article;`
### 2. 서브쿼리 (Subquery)
- **정의**: 쿼리문 안에 포함된 또 다른 쿼리입니다.
- **예시**:
	- `SELECT nickname FROM article WHERE memberId = (SELECT id FROM member WHERE id = 1);`
	- `SELECT * FROM member;`
### 3. 사칙연산
- SQL에서도 기본적인 사칙연산이 가능합니다.
- **예시**:
	- `SELECT 1 + 1 FROM DUAL;`
	- `SELECT 1 - 1 FROM DUAL;`
	- `SELECT 1 * 1 FROM DUAL;`
	- `SELECT 1 / 1 FROM DUAL;`
### 4. 내장 함수 (Built-in Functions)
- **DBMS**가 제공하는 다양한 함수를 사용합니다.
- **주요 함수**:
	- **문자열**: `CONCAT`, `SUBSTR`
		- `CONCAT('asdasd', 'qweqwe')`: 문자를 이어 붙입니다.
		- `SUBSTR('가나다라마바사', 2, 2)`: 문자열을 자릅니다. (날짜 관련해서 자주 사용)
	- **날짜/시간**: `NOW`, `DATEDIFF`
		- `DATEDIFF`: 두 날짜 사이의 차이를 구합니다. (D-DAY 계산)
	- **수학**: `CEIL`, `FLOOR`, `ROUND`
		- `CEIL(1.5)`: 올림
		- `FLOOR(1.3)`: 소수점 버림
		- `ROUND(1.3)`: 반올림 (첫 번째 소수점에서)
	- **집계 함수**: `SUM`, `MIN`, `MAX`, `AVG`, `COUNT`
		- `COUNT`: `NULL` 값을 제외하고 집계합니다.
	- **중복 제거**: `DISTINCT`
		- `DISTINCT`: 중복된 값을 제거합니다.
### 5. `GROUP BY`와 `HAVING`
- **`GROUP BY`**:
	- 집계 함수를 사용한 경우, 집계 함수를 사용하지 않은 컬럼을 `GROUP BY` 절에 모두 나열해야 합니다. (실무에서는 보통 PK를 가지고 그룹화하지 않습니다.)
	- **예시**: `SELECT nickname, SUM(hit) FROM article GROUP BY nickname;`
- **`HAVING`**:
	- `GROUP BY`로 그룹화된 결과에 조건을 적용하는 절입니다.
	- `WHERE` 절과 달리, 집계 함수를 사용한 조건 필터링이 가능합니다.
	- **예시**: `SELECT nickname, SUM(hit) FROM article GROUP BY nickname HAVING SUM(hit) > 10;`
	- **실행 순서**: `FROM` -\> `WHERE` -\> `GROUP BY` -\> `HAVING` -\> `SELECT` -\> `ORDER BY`
### 6. 테이블 분리 (정규화)
- **장점**: 의존성이 낮아 데이터 수정 시 작업량이 적습니다.
- **단점**: 문제 해결이 복잡해집니다.
- **비교**:
	- **하나의 테이블**: 문제 해결이 직관적이지만 의존성이 높아 데이터 수정 시 할 일이 많아집니다.
### 7. `JOIN`
- **정의**: 여러 개의 테이블을 하나로 합치는 기능입니다.
- **종류**:
	- **INNER JOIN**: 두 테이블에 모두 일치하는 행만 반환합니다.
		- `SELECT * FROM t_order JOIN t_user ON t_order.userNo = t_user.id;`
	- **LEFT JOIN**: 왼쪽 테이블을 기준으로, 왼쪽 테이블의 모든 행과 오른쪽 테이블에서 일치하는 행을 반환합니다.
		- `SELECT * FROM t_order AS o LEFT JOIN t_user AS u ON o.userNo = u.id;`
	- **RIGHT JOIN**: 오른쪽 테이블을 기준으로, 오른쪽 테이블의 모든 행과 왼쪽 테이블에서 일치하는 행을 반환합니다.
	- **FULL OUTER JOIN**: 양쪽 테이블의 모든 행을 반환합니다.
### 8. 서브쿼리의 종류
- **스칼라 서브쿼리**: 하나의 값을 반환합니다.
	- **예시**: 
	```sql
WHERE p.price = (SELECT MAX(price) FROM t_product)
	```
- **인라인 뷰 (Inline View)**: 테이블처럼 사용되는 서브쿼리입니다.
	- **예시**:SQL
		
		```sql
SELECT sub.userId, sub.cnt
FROM (
    SELECT userId, COUNT(id) AS `cnt`
    FROM t_order AS o
    INNER JOIN t_user AS u
    ON o.userNo = u.id
    GROUP BY u.userId
    ORDER BY `cnt` DESC
    LIMIT 3
) AS sub
LIMIT 1;
		```
- **EXISTS 서브쿼리**: 존재 여부를 확인합니다.
	- **예시**:SQL
		
		```sql
SELECT u.userName
FROM t_user AS u
WHERE EXISTS (
    SELECT 1
    FROM t_order AS o
    INNER JOIN t_product AS p
    ON o.productNo = p.id
    WHERE o.userNo = u.id
    AND p.pname = '스커트'
);
		```
### 9. `WITH AS` (CTE: Common Table Expression)
- **정의**: 두 개 이상의 쿼리 결과를 합쳐서 다른 쿼리에 연결할 때 사용합니다.
- **예시**:SQL
	
```sql
WITH test1 AS (
    SELECT * FROM t_user
), test2 AS (
    SELECT * FROM t_order
)
SELECT * FROM test1;
```
- **실행 속도**: 서브쿼리 -\> `JOIN` -\> `WITH AS` 순으로 빠릅니다. (일반적으로 `JOIN`이 `WITH AS`보다 성능이 좋습니다.)

    INNER JOIN t_product AS p
    ON o.productNo = p.id
    WHERE u.userName = '손흥민';

    INNER JOIN t_product AS p
