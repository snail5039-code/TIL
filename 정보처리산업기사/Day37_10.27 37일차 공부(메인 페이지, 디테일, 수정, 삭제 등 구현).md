## 💻 자바 서블릿/JSP 기반 게시판 구현 정리
제공된 내용은 게시판의 **메인 페이지**, **목록 조회** 기능을 구현하는 서블릿과 JSP 코드, 그리고 애플리케이션의 **보안** 및 **구조화**에 대한 개발 코멘트로 구성되어 있습니다.
### 1. 홈 (메인) 페이지 구현

| **구성 요소** | **역할** | **경로/파일** |
| --- | --- | --- |
| **서블릿** | `/usr/home/main` 요청 처리 및 뷰 포워딩 | `HomeServlet.java` |
| **뷰 (JSP)** | 메인 화면 출력 및 게시글 목록 링크 제공 | `/view/main.jsp` |

Java
```java
// HomeServlet.java (일부)
@WebServlet("/usr/home/main")
public class HomeServlet extends HttpServlet {
    // ...
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        // /view/main.jsp로 포워딩
        request.getRequestDispatcher("/view/main.jsp").forward(request, response);
    }
}
```

### 2. 게시글 목록 조회 기능

| **구성 요소** | **역할** | **경로/파일** |
| --- | --- | --- |
| **서블릿** | `/usr/article/list` 요청 처리, DB 조회, 데이터 전달 | `ListServlet.java` |
| **뷰 (JSP)** | 전달받은 데이터를 HTML 목록 형태로 출력 | `/view/article/list.jsp` |

**주요 코드:**
Java
```java
// ListServlet.java (DB 연결 및 데이터 조회 부분)
protected void doGet(HttpServletRequest request, HttpServletResponse response)
        throws ServletException, IOException {
    try {
        Class.forName("com.mysql.cj.jdbc.Driver");
        Connection con = DriverManager.getConnection("jdbc:mysql://localhost:3306/JSP_AM", "root", "");

        List<Article> articles = new ArrayList<>();
        Statement stmt = con.createStatement();
        ResultSet rs = stmt.executeQuery("select * from article order by id desc");
        
        // ResultSet에서 데이터를 Article 객체로 변환하여 List에 저장하는 로직 생략
        
        request.setAttribute("articles", articles);
        
        stmt.close();
        con.close();
    } catch (Exception e) {
        e.printStackTrace();
    }
    request.getRequestDispatcher("/view/article/list.jsp").forward(request, response);
}
```

Java
```java
<%-- list.jsp (데이터 출력 부분) --%>
<%@page import="com.koreaIT.servletAM.dto.Article"%>
<%@page import="java.util.List"%>
<%
	List<Article> articles = (List<Article>) request.getAttribute("articles");
%>
<!DOCTYPE html>
<html>
<body>
    <h2>게시판 목록</h2>
    <ul>
		<li><a href="/usr/article/detail?num=1"><%=articles.get(0).getId()%>, <%=articles.get(0).getTitle()%>, <%=articles.get(0).getRegDate()%></a></li>
        </ul>
</body>
</html>
```

### 3. 보안 (SQL Injection) 관련 코멘트
문제점:
사용자 입력값을 그대로 SQL 쿼리 문자열에 합치는 방식은 SQL 인젝션 공격에 매우 취약합니다.
**위험 예시:**
SQL
```java
- 로그인 쿼리 예시
select * from `member` where loginId = '사용자ID' and loginPw = '';
-- 공격: loginPw에 ' or 1 = 1 -- ' 입력 시
select * from `member` where loginId = '사용자ID' and loginPw = '' or 1 = 1 -- ';
-- 쿼리 전체가 참이 되어 데이터베이스의 모든 정보를 조회할 수 있게 됨
```

### 4. 웹 구조화 및 기능 확장 아이디어

| **주제** | **목적** | **사용 예시** |
| --- | --- | --- |
| **인클루드 (Include)** | `header.jsp`, `footer.jsp`와 같이 공통 요소를 분리하여 재사용 | `<%@ include file="/view/common/header.jsp" %>` |
| **`<table>`**** 태그** | 데이터를 행과 열로 구조화하여 표시 (`<tr>`, `<td>`, `<th>`) | `<table border="1">` |
| **셀 병합** | 테이블에서 컬럼이나 로우를 합칠 때 사용 | `<td colspan="2">` 또는 `<td rowspan="2">` |
| **글쓰기 폼** | 사용자 입력 (`title`, `content`) 전송 | `<form action="/usr/article/doWrite" method="post">` |
| **입력 요소** | 제목 (`input`), 내용 (`textarea`) 입력 창 생성 | `<input type ="text" name="title" placeholder="제목을 입력하세요">` |
| **폼 전송 타입** | 데이터 변경(추가, 수정)은 **POST**로 전송하고 `doPost()`에서 처리해야 함 | `method="post"` |
| **데이터 삽입** | DB에 데이터를 실제로 추가하는 메서드 | `stmt.executeUpdate("INSERT INTO article (...) VALUES (...)");` |
| **알림 및 이동** | 작업 완료 후 클라이언트에게 메시지를 띄우고 페이지 이동 | `response.getWriter().append("<script>alert('...'); location.replace('/usr/article/list');</script>");` |
