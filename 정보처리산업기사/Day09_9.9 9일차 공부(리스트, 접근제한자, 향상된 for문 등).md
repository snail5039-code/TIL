### **List**
**List**는 배열의 단점인 '크기가 초기화와 동시에 정해지는' 한계를 보완한 컬렉션입니다. 데이터의 **순서**가 있으며, **데이터 중복**이 가능합니다.
Java
`import java.util.ArrayList;<br>import java.util.List;<br><br>class Main {<br>	public static void main(String[] args) {<br>		// 예제 1: 배열을 사용하는 경우<br>		System.out.println("== 예제 1 ==");<br>		int articlesSize = 0;<br>		Article[] articles = new Article[1000];<br>		articles[0] = new Article();<br>		articlesSize++;<br>		articles[1] = new Article();<br>		articlesSize++;<br>		articles[2] = new Article();<br>		articlesSize++;<br>		articles[3] = new Article();<br>		articlesSize++;<br>		articles[4] = new Article();<br><br>		for (int i = 0; ### **컬렉션 프레임워크**
**컬렉션 프레임워크**는 다수의 데이터를 표준화된 방식으로 처리하는 객체들의 집합입니다.
- **Map**: \*\*키(key)\*\*와 **값(value)** 쌍으로 데이터를 저장합니다. 키는 중복될 수 없지만 값은 중복될 수 있습니다. 데이터의 **순서**는 없습니다. 키를 통해 값을 가져옵니다. **제네릭**에는 기본 자료형을 직접 사용할 수 없습니다. (`<String, Integer>`와 같이 래퍼 클래스를 사용해야 합니다.)Java
	`import java.util.HashMap;<br>import java.util.Map;<br><br>// ... main 메서드 안<br>Map<String, Integer> map = new HashMap<>();<br>map.put("a", 10);<br>map.put("b", 20);<br>map.put("a", 30); // "a" 키가 중복되므로 기존 값 10을 30으로 덮어씁니다.<br><br>System.out.println(map.get("b")); // 결과 값: 20`
- **Set**: 데이터의 **순서**가 없고, **중복**을 허용하지 않습니다.
- **Queue**: 선입선출(FIFO) 방식의 자료 구조입니다.

### **반복문 (Loop)**
자바의 주요 반복문은 `while`, `do-while`, `for`, 그리고 **향상된 for문**이 있습니다.<br>**향상된 for문**은 배열이나 리스트의 모든 요소를 **정방향**으로만 순회할 때 편리합니다.
Java
`// ... main 메서드 안<br>int[] arr = new int[5];<br>arr[0] = 10;<br>arr[1] = 20;<br>arr[2] = 30;<br>arr[3] = 40;<br>arr[4] = 50;<br><br>for(int a : arr) {<br>	System.out.println(a);<br>}`

### **접근 제한자 (Access Modifier)**
접근 제한자는 클래스, 변수, 메서드에 대한 접근 권한을 설정하는 키워드입니다.
1. **public**: 패키지에 상관없이 **모든 곳**에서 접근이 가능합니다.
2. **private**: **선언된 클래스 내에서만** 접근이 가능합니다. 이는 **캡슐화**(정보 은닉)를 위해 사용되며, 보통 **getter/setter** 메서드를 통해 간접적으로 데이터에 접근합니다.
3. **protected**: **같은 패키지** 내에서는 자유롭게 접근할 수 있고, **다른 패키지**에서는 해당 클래스를 **상속받은 자식 클래스**에서만 접근할 수 있습니다.
4. **default**: 아무런 접근 제한자를 명시하지 않은 경우로, **같은 패키지** 내에서만 접근이 가능합니다.

### **문자열 관련 메서드**
- `split("/")`: 특정 구분자(`/`)를 기준으로 문자열을 분리합니다.
- `equals()`: 두 문자열의 **값**이 같은지 비교합니다.
- `==`: 두 문자열 변수가 가리키는 **주소**가 같은지 비교합니다. 문자열의 값 비교에는 \*\*`equals()`\*를 사용하는 것이 올바른 방법입니다.
