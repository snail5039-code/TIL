### **자바(Java) 프로그래밍 학습 내용 정리**
### 1. 자바(Java)의 기본 구조와 동작 원리
자바는 **객체 지향 프로그래밍(OOP)** 언어입니다. 사람이 작성한 코드는 **컴파일러**를 통해 컴퓨터가 이해하는 언어로 변환됩니다. 자바는 \*\*JVM(Java Virtual Machine)\*\*이라는 컴파일러 덕분에 이 과정이 자동으로 이루어집니다.
- **프로젝트(Project):** 코드를 작성하고 관리하는 최상위 폴더입니다.
- **클래스 파일(Class File):** 자바의 기본 구성 요소이며, 이름은 **대문자**로 시작해야 합니다.
- **메인 메서드(main method):** `public static void main(String[] args)` 형태로, 프로그램의 **시작점** 역할을 합니다.

| 파일 종류 | 확장자 | 특징 |
| --- | --- | --- |
| 소스 파일 | `.java` | 사람이 작성하는 코드 파일 |
| 컴파일된 파일 | `.class` | JVM이 실행하는 바이트 코드 파일 |

### 2. 디버깅(Debugging)과 코드 작성 유의사항
**디버깅**은 코드의 오류를 찾아내고 수정하는 과정입니다. 디버깅을 잘하면 문제 해결 능력이 향상됩니다.
- **가독성:** 코드를 다른 사람이 쉽게 읽을 수 있도록 작성하는 것이 중요합니다.
	- **들여쓰기:** 코드 블록(`{}`) 안의 코드는 탭으로 들여씁니다.
	- **줄 바꿈 및 띄어쓰기:** 논리적으로 코드를 구분하여 읽기 편하게 만듭니다.
- **최적화:** 코드가 더 효율적으로 실행되도록 만드는 과정입니다.

### 4. 출력문과 변수
### 1) 출력(Output)
**출력**은 코드 실행 결과를 눈으로 확인하는 과정입니다. 자바는 주로 **콘솔**에 결과를 보여줍니다.
- **`System.out.println()`**: 괄호 안의 내용을 출력하고 줄을 바꿉니다.
- **`System.out.print()`**: 괄호 안의 내용을 출력하지만, 줄 바꿈을 하지 않습니다.
- **`System.out.printf()`**: 특정 \*\*서식(format)\*\*에 맞춰 값을 출력합니다. 예를 들어 `%d`는 정수를 출력하는 서식입니다.
- **예시:** `System.out.println("Hello World ~ !!");`
	- **결과:** Hello World \~ !!
### 2) 변수(Variable)
**변수**는 데이터를 저장하는 공간으로, 값이 변할 수 있습니다.
- **변수 선언:** **`[데이터 타입] [변수명];`** 형태로 변수를 만듭니다.
	- **설명:** `int x;`는 '정수형 데이터만 저장할 수 있는 `x`라는 변수 공간을 만든다'는 의미입니다.
- **변수 초기화:** **`[변수명] = [값];`** 형태로 변수에 값을 처음으로 할당합니다.
	- **설명:** `x = 5;`는 '변수 `x`에 `5`라는 값을 대입한다'는 의미입니다.
- **대입 연산자 (****`=`****):** 우측의 값을 좌측의 변수에 할당하며, **비교 연산자 (****`==`****)와는 다릅니다.**
### 3) 변수 연산 예시
- **예시 1:**
Java
`int x = 10;<br>int y = 20;<br>y = x; // y에 x의 값(10)이 대입됩니다.<br>x = y; // x에 y의 값(10)이 다시 대입됩니다.`
- `**결과:** \`x\`와 \`y\` 모두 \`10\`이 출력됩니다.<br>* **설명:** 변수는 대입 연산자(\`=\`)의 좌변에 위치하지 않으면 값으로 사용됩니다.`
- **예시 2:**
Java
`int x = 10;<br>x = x + 5; // x의 값은 15가 됩니다.<br>int y = 20;<br>System.out.println("x + y : " + x + y);`
- `**결과:** \`x + y : 1520\`<br>* **설명:** 문자열과 숫자가 \`+\`로 연결되면, 숫자가 문자열로 자동 변환되어 "15"와 "20"이 붙어서 출력됩니다.`

### 5. 기본 자료형과 변수 명명 규칙
### 1) 기본 자료형(Primitive Data Types)
자바에는 데이터를 저장하는 8가지의 기본 자료형이 있습니다.

| 분류 | 자료형 | 설명 |
| --- | --- | --- |
| **정수형** | `byte`, `short`, `int`, `long` | 소수점이 없는 숫자를 저장합니다. `int`가 가장 일반적으로 사용됩니다. |
| **실수형** | `float`, `double` | 소수점이 있는 숫자를 저장합니다. `double`이 더 정밀합니다. |
| **문자형** | `char` | 한 개의 문자를 저장합니다. `' '` (작은따옴표)로 감쌉니다. |
| **논리형** | `boolean` | `true` 또는 `false` 값을 저장합니다. |

### 2) 참조형(Reference Type)
기본 자료형 8가지를 제외한 모든 타입은 **참조형**입니다. 대표적인 예로 \*\*`String`\*\*이 있습니다. 참조형 변수의 기본값은 **`null`** (데이터가 없음을 의미)입니다.
- **예시:** `String a = null;` vs `String a = "";`
	- **설명:** `null`은 데이터가 없음을 의미하는 반면, `""`는 빈 문자열이라는 데이터가 존재함을 의미합니다.
### 3) 변수 명명 규칙 (Naming Conventions)
변수 이름은 가독성과 통일성을 위해 다음 규칙을 따르는 것이 좋습니다.

| 규칙 | 설명 | 예시 |
| --- | --- | --- |
| **카멜 케이스 (Camel Case)** | 첫 단어는 소문자, 이어지는 단어의 첫 글자는 대문자로 시작합니다. **(자바의 관례)** | `computerMonitor` |
| **파스칼 케이스 (Pascal Case)** | 모든 단어의 첫 글자를 대문자로 시작합니다. (클래스 이름에 사용) | `ComputerMonitor` |
| **스네이크 케이스 (Snake Case)** | 단어들을 언더바(`_`)로 연결합니다. | `computer_monitor` |

### 6. 제어문법: 조건문과 반복문
### 1) 조건문 (Conditional Statements)
주어진 조건에 따라 다른 코드를 실행하도록 합니다.
- **`if`****문:** 가장 기본적인 조건문입니다. `if (조건) { ... }` 형태로 사용합니다.
- **`else`****문:** `if` 조건이 거짓일 경우 실행됩니다.
- **`else if`****문:** 여러 개의 조건을 차례로 검사할 때 사용합니다.
- **`switch`****문:** 특정 값에 따라 다른 코드를 실행할 때 사용하며, `case`와 `break`를 활용합니다. `if`문보다 조건이 명확할 때 효율적입니다.
- **조건문 예시:**
Java
`int age = 20;<br><br>if(age >= 20) {<br>    System.out.println("성인");<br>} else {<br>    System.out.println("미성년자");<br>}`
- `**결과:** 성인<br>* **설명:** \`age\`가 \`20\`보다 크거나 같으므로 첫 번째 조건이 참이 되어 "성인"이 출력됩니다.`
- **`switch`****문 예시:**
Java
`int age = 20;<br>switch (age) {<br>    case 10:<br>        System.out.println("10대");<br>        break;<br>    case 20:<br>        System.out.println("20대");<br>        break;<br>    default:<br>        System.out.println("그 외");<br>        break;<br>}`
- `**결과:** 20대<br>* **설명:** \`age\`의 값과 일치하는 \`case 20\`의 코드가 실행되고, \`break\`를 만나 \`switch\`문을 빠져나갑니다.`

### 7. 에러(Error) 종류
- **컴파일 에러:** 문법적 오류로, 코드가 실행되기 전에 발생합니다. (빨간색 에러)
- **예외(Exception):** 코드는 문법적으로 문제가 없지만, 실행 중에 발생하는 오류입니다.
- **경고(Warning):** 코드에 잠재적인 문제가 있지만, 실행에는 영향을 주지 않습니다. (노란색 느낌표)
