## 1. 검색 기능 입력값 검증의 중요성 ⚠️
사용자님이 언급하신 내용은 소프트웨어 개발에서 매우 중요한 \*\*입력 유효성 검사(Input Validation)\*\*에 해당합니다.
### 정리된 내용
검색 기능을 구현할 때, 사용자가 입력하는 값(예: `searchType`, `searchKeyword`)이 프로그램이 **예상하는 데이터 타입과 형식**을 갖추고 있는지 반드시 확인해야 합니다.
- **문제 예측:** 현재 `searchType`이나 `searchKeyword`가 문자열(String)로 예상되는데, 만약 예기치 않게 숫자(Int)와 같은 다른 타입이 입력되거나, 데이터베이스에서 값을 가져오는 과정에서 예상치 못한 `null` 값이 처리된다면 \*\*널 포인터 예외(NullPointerException)\*\*와 같은 심각한 오류가 발생할 수 있습니다.
- **해결책:** 서버로 값이 전달되기 전에 해당 값이 **`null`****이 아닌지**, **원하는 데이터 타입**인지, 그리고 **보안상 안전한지** 등을 검증하는 로직을 추가해야 합니다.
### 추가 설명 (보안 및 데이터 타입)
1. **데이터 타입 검증:** 문자열이 와야 하는 자리에 숫자가 오지 않도록, 혹은 특정 길이를 초과하지 않도록 검사해야 합니다.
2. **널(Null) 값 처리:** 값이 비어있을 경우(null) 예외를 발생시키기보다, 기본값(Default Value)을 설정하거나, 오류 메시지를 사용자에게 보여주는 방식으로 처리해야 합니다.
3. **보안 강화 (SQL Injection 방지):** 사용자가 입력한 검색 키워드에 악성 코드가 포함되어 있는지 확인하고, 이를 방지하기 위해 **PreparedStatement**와 같은 안전한 방식을 사용하는 것이 필수적입니다.

## 2. JSTL을 활용한 선택 상태 유지 (UI 구현) 🖱️
사용자님이 제시하신 코드는 웹 페이지에서 **사용자의 이전 선택 상태를 기억**하여 UI의 편의성을 높이는 표준적인 방법입니다.
### 정리된 내용
JSP 환경에서 \*\*JSTL(JSP Standard Tag Library)\*\*의 `<c:if>` 태그를 사용하여 드롭다운 메뉴(`select` 태그)나 라디오 버튼 등에서 사용자가 이전에 선택했던 값을 유지할 수 있습니다.
- **원리:** 페이지가 다시 로드될 때, 요청 파라미터(`param` 객체)에 저장된 이전 값(`param.searchType`)과 현재 옵션의 값('title')을 비교합니다.
- **작동:** 두 값이 일치할 경우 HTML `<option>` 태그 안에 `selected` 속성을 삽입하여 해당 옵션이 미리 선택된 상태로 화면에 표시되게 합니다.
### 코드 예시
HTML
```java
<select name="searchType">
    <option value="title" <c:if test="${param.searchType == 'title' }">selected</c:if>>제목</option>
    <option value="content" <c:if test="${param.searchType == 'content' }">selected</c:if>>내용</option>
    <option value="writer" <c:if test="${param.searchType == 'writer' }">selected</c:if>>작성자</option>
</select>
```

### 추가 설명 (사용자 경험 개선)
- **사용자 경험(UX) 향상:** 검색 결과 페이지로 이동했다가 다시 돌아왔을 때, 이전 검색 조건이 그대로 유지되면 사용자는 혼란 없이 다음 작업을 이어갈 수 있어 매우 편리해집니다.
- **다른 방법:** `<c:if>` 대신 **`<c:set>`** 태그를 사용하여 변수에 `selected` 문자열을 담아 사용하는 방법이나, **`<c:choose>`**** / ****`<c:when>`**** / ****`<c:otherwise>`** 구조를 사용하면 여러 조건을 동시에 처리할 때 코드를 더 깔끔하게 만들 수 있습니다.
**`<c:choose>`**** 사용 예시:**
HTML
```java
<select name="searchType">
    <c:choose>
        <c:when test="${param.searchType == 'title'}">
            <option value="title" selected>제목</option>
        </c:when>
        <c:otherwise>
            <option value="title">제목</option>
        </c:otherwise>
    </c:choose>
    </select>
```

```java
package com.example.demo.controller;

import com.example.demo.dao.ArticleDao;
import com.example.demo.vo.Article;
import com.example.demo.vo.Rq; // 요청자님 환경에 맞춘 Rq 객체 사용
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.stereotype.Controller;
import org.springframework.ui.Model;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;

import java.util.HashMap;
import java.util.List;
import java.util.Map;

@Controller
@RequestMapping("/usr/article")
public class UsrArticleController {

    @Autowired
    private ArticleDao articleDao;

    // 페이지당 게시글 수
    private final int itemsPerPage = 10;
    // 페이징 버튼 범위 (예: 1 2 3 ... 10)
    private final int pageRange = 10;

    @RequestMapping("/list")
    public String showList(
            Model model,
            Rq rq, // Rq 객체 (로그인 정보 등에 사용된다고 가정)
            @RequestParam(defaultValue = "1") int boardId,
            @RequestParam(defaultValue = "1") int cPage,
            @RequestParam(defaultValue = "") String searchType,
            @RequestParam(defaultValue = "") String searchKeyWord
    ) {
        // 검색 키워드 및 타입 정리 (null 처리)
        searchKeyWord = searchKeyWord.trim();
        searchType = searchType.trim();

        // 1. 게시판 이름 조회
        String boardName = articleDao.getBoardNameById(boardId);
        if (boardName == null) {
            // 예외 처리 (없는 게시판)
            return "redirect:/";
        }

        // 2. 검색 조건 매개변수 Map 구성
        Map<String, Object> param = new HashMap<>();
        param.put("boardId", boardId);
        param.put("searchType", searchType);
        param.put("searchKeyWord", searchKeyWord);

        // 3. 전체 게시글 수 조회
        int articlesCnt = articleDao.getArticlesCnt(param);
        
        // 4. 페이징 계산
        int totalPagesCnt = (int) Math.ceil((double) articlesCnt / itemsPerPage);
        
        // cPage 유효성 검사
        if (cPage < 1) cPage = 1;
        if (cPage > totalPagesCnt && totalPagesCnt > 0) cPage = totalPagesCnt;

        // 5. 게시글 목록 조회 파라미터 추가
        int limitStart = (cPage - 1) * itemsPerPage;
        param.put("limitStart", limitStart);
        param.put("limitTake", itemsPerPage);

        List<Article> articles = articleDao.getArticles(param);
        
        // 6. 페이지 버튼 범위 계산
        int begin = ((cPage - 1) / pageRange) * pageRange + 1;
        int end = begin + pageRange - 1;
        if (end > totalPagesCnt) {
            end = totalPagesCnt;
        }

        // 7. Model에 데이터 담기 (JSP에서 사용할 변수 이름과 일치시킴)
        model.addAttribute("boardName", boardName);
        model.addAttribute("articlesCnt", articlesCnt);
        model.addAttribute("articles", articles);
        model.addAttribute("searchKeyWord", searchKeyWord);
        
        // 페이징 관련 정보
        model.addAttribute("cPage", cPage);
        model.addAttribute("totalPagesCnt", totalPagesCnt);
        model.addAttribute("begin", begin);
        model.addAttribute("end", end);
        model.addAttribute("req", rq); // JSP의 ${req...}에 맞춰 Rq 객체 전달

        return "usr/article/list"; // JSP 경로
    }
}
```

DAO
```java
package com.example.demo.dao;

import java.util.List;

import org.apache.ibatis.annotations.Delete;
import org.apache.ibatis.annotations.Insert;
import org.apache.ibatis.annotations.Mapper;
import org.apache.ibatis.annotations.Select;
import org.apache.ibatis.annotations.Update;

import com.example.demo.dto.Article;

@Mapper
public interface ArticleDao {

	@Insert("""
			INSERT INTO article
				SET regDate = NOW()
					, updateDate = NOW()
					, memberId = #{loginedMemberId}
					, title = #{title}
					, content = #{content}
					, boardId = #{boardId}
			""")
	public void writeArticle(String title, String content, int loginedMemberId, int boardId);

	@Select("""
			<script>
			SELECT COUNT(id)
				FROM article
				WHERE boardId = #{boardId}
				<if test="searchKeyWord != null and searchKeyWord != ''">
			    	and 
			    	<choose>
			    	  	<when test="searchType == 'titleAndContent'">
			    	  	  	(title like concat ('%',#{searchKeyWord},'%')
			    	  	  	or content like concat('%',#{searchKeyWord},'%'))
			    		</when>

			    		<when test="searchType == 'title'">
				    		title like concat ('%',#{searchKeyWord},'%')
			    		</when>

			    		<when test="searchType == 'content'">
				    		content like concat ('%',#{searchKeyWord},'%')
			    		</when>
			    	</choose>
		    	</if>
		  	</script>
			""")
	public int getArticlesCnt(int boardId, String searchKeyWord, String searchType);

	@Select("""
			<script>
			SELECT a.id
			        , a.regDate
			        , a.title
			        , m.loginId AS `writerName`
			    FROM article AS a
			    INNER JOIN `member` AS m
			    ON a.memberId = m.id
			    WHERE a.boardId = #{boardId}
		    	<if test="searchKeyWord != null and searchKeyWord != ''">
			   		and
		    	  	  
			   		<choose>
		    	  	    <when test="searchType == 'titleAndContent'">
			    	  	  	(a.title like concat ('%',#{searchKeyWord},'%')
			    	  	  	or a.content like concat('%',#{searchKeyWord},'%'))
			    		</when>
	
			    		<when test="searchType == 'title'">
				    		a.title like concat ('%',#{searchKeyWord},'%')
			    		</when>
	
			    		<when test="searchType == 'content'">
				    		a.content like concat ('%',#{searchKeyWord},'%')
			    		</when>

		    		</choose>
	    		</if>
			    ORDER BY a.id DESC
			    LIMIT #{limitFrom}, #{itemsInAPage}
		   </script>
			""")
	public List<Article> showList(int boardId, int limitFrom, int itemsInAPage, String searchKeyWord,
			String searchType);

	@Select("""
			SELECT a.*
					, m.loginId AS `writerName`
				FROM article AS a
			    INNER JOIN `member` AS m
			    ON a.memberId = m.id
				WHERE a.id = #{id}
			""")
	public Article getArticleById(int id);

	@Update("""
			<script>
			UPDATE article
				SET updateDate = NOW()
					<if test="title != null and title != ''">
						, title = #{title}
					</if>
					<if test="content != null and content != ''">
						, content = #{content}
					</if>
				WHERE id = #{id}
			</script>
			""")
	public void modifyArticle(int id, String title, String content);

	@Delete("""
			DELETE FROM article
				WHERE id = #{id}
			""")
	public void deleteArticle(int id);

	@Select("SELECT LAST_INSERT_ID()")
	public int getLastInsertId();

	
	@Select("""
			select count(*)
				from goodPoint
				where memberId = #{loginedMemberId}
						and rsId = #{rsId}
			""")
	public int getGoodPoint(int loginedMemberId, int rsId);

	@Delete("""
			delete from goodPoint
				where memberId = #{memberId}
				and rsId = #{rsId}
			""")
	public void deleteGoodPoint(int memberId, int rsId);

	@Select("""
			select count(*)
				from goodPoint
				where rsId = #{rsId} 
			""")
	public int getGoodCnt(int rsId);

	@Insert("""
			insert into goodPoint
				set memberId = #{loginedMemberId}
					, rsId = #{rsId}
			""")
	public void addGoodPoint(int loginedMemberId, int rsId);

}
```
