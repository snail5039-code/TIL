### **증감 연산자 및 대입 연산자**
증감 연산자는 변수의 값을 **1씩 증가**시키거나 **1씩 감소**시키는 연산자를 말합니다. `i = i + 1;`, `i += 1;`, `i++;` 모두 `i`의 값을 1씩 증가시키는 동일한 역할을 합니다.
대입 연산자는 특정 연산을 수행한 후 그 결과를 다시 변수에 할당하는 연산자입니다. 예를 들어, `i += 1;`은 `i = i + 1;`과 같습니다. 이 외에도 `*=`, `/=`, `-=`, `%=` 등의 종류가 있습니다.

---

### **증감 연산자의 종류: 전위 연산자와 후위 연산자**
증감 연산자는 연산자가 변수의 앞에 오는지(전위) 뒤에 오는지(후위)에 따라 실행 순서가 달라집니다.
- **후위 연산자 (i++)**
	- `i++`는 해당 연산자가 포함된 **코드가 실행된 후**에 값을 증가시킵니다.
	- **예시:**`int i = 0;System.out.println(i++);` // 먼저 `i`의 현재 값(0)을 출력한 후, `i`의 값을 1 증가시킴.<br>`System.out.println(i);` // 다음 출력에서는 증가된 값(1)이 나옴.
- **전위 연산자 (++i)**
	- `++i`는 해당 연산자가 포함된 **코드가 실행되기 전**에 먼저 값을 증가시킵니다.
	- **예시:**`int i = 0;System.out.println(++i);` // 먼저 `i`의 값을 1 증가시킨 후(1), 증가된 값(1)을 출력.
	- 일반적으로 후위 연산자가 더 자주 사용됩니다.

### **반복문 (Loop)**
반복문은 특정 조건을 만족하는 동안 동일한 코드를 반복해서 실행하는 문법입니다. 모든 프로그램은 반복문을 통해 만들어진다고 해도 과언이 아닙니다.
반복문을 구성하는 세 가지 필수 요소는 다음과 같습니다.
1. **초기값**: 반복을 시작하는 값
2. **종료 조건**: 반복을 멈추는 조건
3. **스텝**: 반복할 때마다 값이 변하는 정도 (예: 1씩 증가 또는 감소)
### **1. while문**
`while (조건식)` 형태이며, 조건식이 참(true)일 동안 코드 블록 `{}`을 반복 실행합니다.
- **기본 구조:**`while (조건식) { // 실행할 코드}`
- **예시:**
	- **무한 루프:**`while (2 > 1) { System.out.println("출력 1");}`
		- 조건 `2 > 1`은 항상 참이므로 무한히 반복됩니다.
	- **특정 횟수 반복:**`int i = 1;while (i <= 5) { System.out.println("출력 i");` <br>` i++;}`
		- `i`의 값이 1부터 5까지 1씩 증가하며 총 5번 반복됩니다.
- **'안녕하세요' 3번 반복 예시:**`int j = 1;while(j < 4) { System.out.println("안녕하세요"); j++;}`
	- `j`가 1부터 3까지 1씩 증가하며 "안녕하세요"를 총 3번 출력합니다.
### **2. for문**
`for (초기값; 조건식; 스텝)` 형태이며, while문보다 반복문의 필수 요소들을 한 줄에 명시하여 더 간결하게 표현할 수 있습니다.
- **기본 구조:**`for (int i = 1; i <= 5; i++) { // 실행할 코드}`
- **무한 루프:**`for (;;) { System.out.println(1);}`
	- `for`문의 괄호 안을 비워두면 조건이 항상 참이므로 무한 루프가 됩니다.

---

### **중첩 반복문 (Nested Loops)**
반복문 안에 또 다른 반복문이 포함된 구조를 말합니다.
- **동작 원리:** 바깥쪽 반복문이 한 번 실행될 때, 안쪽 반복문은 정해진 횟수만큼 모두 반복됩니다.
	- **예시:** 구구단 표 출력 시, 바깥 반복문은 단을 제어하고 안쪽 반복문은 곱해지는 수를 제어합니다.
	### **예시: 구구단 출력**
	구구단 2단부터 9단까지 출력하는 코드를 중첩 반복문을 사용하여 작성할 수 있습니다.
	`// 바깥쪽 반복문: 단(2단 ~ 9단)을 제어<br>for (int i = 2; i < 10; i++) {<br>    // 안쪽 반복문: 곱해지는 수(1 ~ 9)를 제어<br>    for (int j = 1; j < 10; j++) {<br>        System.out.println(i + " * " + j + " = " + (i * j));<br>    }<br>}`
	- **동작 방식:**
		1. 바깥쪽 `for`문에서 `i`가 2가 되어 한 번 실행됩니다.
		2. 이때 안쪽 `for`문이 `j`를 1부터 9까지 증가시키며 2단 전체를 출력합니다.
		3. 안쪽 `for`문이 종료되면, 다시 바깥쪽 `for`문으로 돌아가 `i`가 3으로 증가합니다.
		4. 안쪽 `for`문이 다시 `j`를 1부터 9까지 증가시키며 3단 전체를 출력합니다.
		5. 이 과정이 `i`가 9가 될 때까지 반복되어 모든 단이 출력됩니다.

---

### **반복 제어문: break & continue**
반복문의 흐름을 제어하는 키워드입니다.
- **`break`**: 현재 반복문을 즉시 **종료**하고 반복문 바깥으로 빠져나갑니다.
- **`continue`**: 현재 반복문의 나머지 부분을 건너뛰고 **다음 반복**을 시작하기 위해 반복문의 시작점으로 돌아갑니다.
