### **객체 및 객체지향 프로그래밍(OOP)**
**객체**는 주체(나)를 제외한 모든 것을 의미합니다. 프로그래밍에서는 프로그램 내의 모든 것이 객체가 될 수 있습니다. 자바는 \*\*객체지향 프로그래밍(OOP)\*\*에 특화된 언어로, 사람이 사용하기 편리하게 만들어졌습니다. 자바에서 코드를 작성할 때는 반드시 **클래스**가 필요하며, 클래스는 곧 객체를 의미합니다.

---

### **변수와 객체 (배열)**
**변수**는 단 하나의 값만 저장할 수 있는 공간입니다. 예를 들어, `int a = 10;`은 정수형 변수 `a`에 값 `10`을 할당하는 것입니다. 반면, **객체**는 여러 개의 연관된 데이터를 묶어서 다룰 때 사용하는 문법으로, **배열**이 대표적인 객체입니다. 배열은 데이터에 순서(인덱스)가 있으며, 여러 값을 저장할 수 있습니다.
**배열 객체 생성 및 접근 예시**
Java
`// 변수 선언 및 초기화<br>// 오직 정수형 데이터들만 들어갈 수 있는 arr라는 변수를 만들고<br>// int[3] 모양으로 된 객체 하나를 만들고<br>// 해당 객체를 컨트롤 할 수 있는 리모컨을 연결시키겠다.<br>int[] arr = new int[3];<br><br>// 인덱스에 접근하여 값 할당<br>arr[0] = 10;<br>arr[1] = 20;<br>arr[2] = 30;<br><br>// 배열의 크기(길이)를 알아내는 방법<br>int length = arr.length;`
**다른 배열 객체 생성 방법**
배열을 선언과 동시에 초기화하는 방법도 있습니다.
Java
`// 배열일 때만 사용 가능하며, 잘 사용되지 않음<br>int[] arr2 = {10, 20, 30};`
배열은 참조형이므로 `null` 값을 가질 수 있습니다.
Java
`// 참조형이므로 null이 가능하다.<br>int[] arr3 = null;`
또한, 2차원 배열을 사용하여 행과 열을 가진 데이터를 다룰 수 있습니다.
Java
`// 2차원 배열<br>int[][] arr4 = new int[3][5];`
**객체를 사용하는 이유**는 여러 데이터를 묶어서 한 번에 처리하고 전달하기 용이하기 때문입니다.

### **예외 처리 (Exception Handling)**
**예외 처리**는 프로그램 실행 중 발생할 수 있는 오류를 미리 예측하고 처리하는 방법입니다. 자바에서는 주로 **`try-catch`** 문을 사용합니다. `try` 블록에서 예외가 발생할 가능성이 있는 코드를 작성하고, `catch` 블록에서 발생한 예외를 처리합니다.
**예외 처리 코드 예시**
Java
`// 자바에서는 예외처리를 try, catch로 한다<br>try {<br>	int[] arr = new int[5];<br>		<br>	for(int i = 0; i < 10; i++) {<br>		arr[i] = 10 * (i + 1);<br>		System.out.println(arr[i]);<br>	}<br>	<br>} catch (ArrayIndexOutOfBoundsException e) {<br>	System.out.println("배열의 인덱스 범위 초과!");<br>	// 여러개의 예외 상황을 추가 할 수 있다.<br>} catch (IllegalFormatConversionException e) {<br>	System.out.println("숫자양식 예외 발생!");<br>} catch (Exception e) {<br>	System.out.println("포괄적인 예외 발생!");<br>} finally {<br>	System.out.println("finally 블록은 예외 발생 여부와 상관없이 항상 실행됩니다.");<br>}`
`finally` 블록은 예외 발생 여부와 관계없이 항상 실행되는 코드를 작성할 때 사용합니다. `throw` 키워드를 사용해 예외를 직접 던지는 방법도 있습니다.

### **변수의 종류 및 자료형**
**변수의 종류**는 선언 위치에 따라 **전역 변수**, **멤버 변수**, **지역 변수**로 나눌 수 있습니다.
- **전역 변수:** 자바에는 실질적인 전역 변수가 없으며, \*\*`static` 변수(클래스 변수)\*\*가 그 개념을 대체합니다.
- **멤버 변수 (필드):** 클래스 안에서, 메서드 밖에서 선언된 변수로, 같은 클래스 내 모든 메서드에서 사용 가능합니다. 초기값을 지정하지 않으면 기본값으로 자동 초기화됩니다.
- **지역 변수:** 메서드나 코드 블록 내에서 선언된 변수로, 선언된 블록 내에서만 사용 가능하며, 사용 전에 반드시 초기화해야 합니다.
- \*기본 자료형(Primitive Type)\*\*과 **래퍼 클래스(Wrapper Class)**
자바의 기본 자료형 8가지 (`byte`, `short`, `int`, `long`, `float`, `double`, `boolean`, `char`)는 각각에 대응하는 **클래스** 형태로도 존재합니다. 이들을 **래퍼 클래스**라고 부릅니다.
//	byte -\> Byte<br>//	short -\> Short		<br>//	int -\> Integer<br>//	long -\> Long<br>//	float -\> Float<br>//	double -\> Double<br>//	boolean -\> Boolean<br>//	char -\> Character

### **객체지향 프로그래밍(OOP)의 4가지 특징**
1. **추상화 (Abstraction):** 필요한 부분만 추출하여 간결하게 표현하는 것. 예를 들어, 자동차를 만들 때 바퀴, 핸들 등 핵심적인 특징만 뽑아내는 것을 들 수 있습니다.
2. **상속 (Inheritance):** 기존 클래스의 속성과 기능을 물려받아 새로운 클래스를 만드는 것.
3. **다형성 (Polymorphism):** 하나의 객체가 여러 형태를 가질 수 있는 것.
4. **캡슐화 (Encapsulation):** 데이터와 기능을 하나의 단위로 묶고, 외부에서 직접 접근하지 못하도록 보호하는 것.

### **사용자 정의 객체**
**사용자 정의 객체**는 개발자가 직접 설계하여 만든 객체입니다. 객체는 데이터를 저장하는 \*\*속성(변수)\*\*과 동작을 수행하는 \*\*기능(메서드)\*\*으로 구성됩니다.
**사용자 정의 객체와 메서드 예시**
Java
`class Main {<br>	public static void main(String[] args) {<br><br>		// 사람 클래스를 기반으로 a철수 객체 생성<br>		사람 a철수 = new 사람();<br>		a철수.이름 = "김철수";<br>		a철수.나이 = 20;<br>		<br>		System.out.println(a철수.이름); // 출력: 김철수<br>		System.out.println(a철수.나이); // 출력: 20<br>		<br>		// 메서드 호출<br>		a철수.메서드명();<br>	}<br>}<br><br>// 설계도(클래스)<br>class 사람 {<br>	// 속성(변수)<br>	String 이름;<br>	int 나이;<br>	<br>	// 기능(메서드)<br>	void 메서드명() {<br>		System.out.println("메서드가 호출되었습니다.");<br>	}<br>}`

- **메서드**는 클래스 내부에 정의된 함수입니다. 자바에서는 독립적인 함수를 만들 수 없고, 반드시 클래스 안에 속해야 합니다.
- `void`는 메서드가 반환하는 값이 없음을 의미합니다.

---

### **재귀 함수와 명시적 초기화**
- **재귀 함수 (Recursive Function):** 메서드가 자기 자신을 다시 호출하는 행위를 말하며, **팩토리얼** 계산 같은 경우에 유용하게 사용됩니다.
- **명시적 초기화:** 변수를 선언함과 동시에 값을 지정하는 것을 말합니다. 클래스 변수에서 주로 사용하며, **`final`** 키워드를 사용하여 상수를 정의할 때 유용합니다.

밑에꺼는 배열 기초 문제 풀이
```java
class Main {
	public static void main(String[] args) {
//		1. 방 10개짜리 정수배열 생성
//		2. 순서대로 10 ~100까지 10씩 증가하는 값 넣기
//		3. 배열이 가진 모든 값 순서대로 출력하기
//		4. 배열이 가진 모든 값의 합계 구하기
//		5. 배열이 가진 모든 값의 평균 구하기
		
		int[] arr = new int[10];
		
		int sum = 0;
		
//		10 * (0~9 + 1)
		
		for(int i = 0; i < arr.length; i++) {
			// 값을 넣는 과정
			arr[i] = 10 * (i + 1);
			
			// 값을 출력하는 과정
			System.out.println(arr[i]);
			
			// 값의 합계를 구하는 과정
			sum += arr[i];
		}
		
		System.out.println("합계 : " + sum);
		System.out.println("평균 : " + sum / arr.length);
	} 
	
}
```
