## 🚀 게시판 좋아요 기능 구현 계획
요청하신 기능의 핵심은 **로그인 상태**에 따른 좋아요 버튼의 **상호작용** 제어와, 페이지 **새로고침 없이** 좋아요 상태 및 개수를 업데이트하는 **비동기** 처리입니다.
### 1. 좋아요 표시 요소 (HTML/CSS)
상세 페이지에서 좋아요 상태를 표시하고 사용자가 클릭할 수 있는 요소를 구성합니다.
- **위치:** 수정일 정보 아래 별도의 행(row)에 배치합니다.
- **구성:**
	- 좋아요 버튼 (아이콘 \$\\hearts\$ 또는 텍스트 '좋아요')
	- 현재 좋아요 개수를 표시하는 영역
HTML
```java
<div class="post-details">
    <div class="like-section">
        <button id="like-button" class="like-btn" data-post-id="{{ post.id }}" data-is-liked="{{ is_user_liked | lower }}">
            <span id="like-icon"></span>
            <span id="like-text">좋아요</span>
        </button>
        <span id="like-count" class="count-display">{{ like_count }}</span>
    </div>
</div>
```

### 2. 백엔드 로직: 좋아요 처리 (서버)
좋아요 추가/취소 요청을 처리하고, 현재 상태와 개수를 반환하는 API 엔드포인트가 필요합니다.
- **기술 스택:** (예: Python/Django, Node.js/Express, Java/Spring 등)
- **엔드포인트:** 보통 `POST /api/posts/{post_id}/like` 와 같은 형태로 만듭니다.
- **처리 순서:**
	1. **인증 확인:** 요청을 보낸 사용자가 **로그인** 상태인지 확인합니다. (로그인이 안 되어 있으면 에러 응답)
	2. **현재 상태 확인:** 해당 사용자가 이 게시글에 이미 좋아요를 눌렀는지 확인합니다.
	3. **좋아요/취소:**
		- 이미 눌렀으면 -\> `좋아요 기록 삭제` (취소)
		- 누르지 않았으면 -\> `좋아요 기록 추가` (등록)
	4. **결과 반환:** 업데이트된 **총 좋아요 개수**와 **사용자의 현재 좋아요 상태**를 JSON 형태로 응답합니다.
JSON
```java
{
    "success": true,
    "current_likes": 42,
    "is_liked": true  // 사용자가 좋아요를 눌렀는지 여부
}
```

### 3. 프론트엔드 로직: 비동기 처리 (JavaScript)
사용자가 좋아요 버튼을 클릭했을 때 **Fetch API**나 **Axios** 등을 사용하여 서버와 통신하고, DOM을 업데이트합니다.
### 🔑 핵심 개념: 비동기 통신 (AJAX/Fetch)
- \*AJAX (Asynchronous JavaScript and XML)\*\*는 웹페이지의 일부분만 업데이트할 수 있게 해주는 기술입니다. 이를 통해 좋아요 버튼을 누르더라도 페이지 전체를 새로고침하지 않고 서버에 요청을 보내고 응답을 받아 버튼 상태와 개수만 즉시 변경할 수 있습니다.
JavaScript
```java
document.addEventListener('DOMContentLoaded', function() {
    const likeButton = document.getElementById('like-button');
    const likeCountSpan = document.getElementById('like-count');
    const postId = likeButton.dataset.postId;
    let isUserLoggedIn = {{ user_authenticated | lower }}; // 백엔드에서 로그인 상태 전달

    // 로그인 상태가 아닐 경우, 버튼 클릭 이벤트 막기
    if (!isUserLoggedIn) {
        likeButton.addEventListener('click', function(event) {
            // event.preventDefault(); // 클릭 기본 동작 방지 (필요하다면)
            alert('로그인 후 이용해 주세요.');
        });
        // 로그인 안 한 사용자에게는 버튼을 disabled 상태로 시각적으로 보여줄 수 있습니다.
        likeButton.disabled = true;
        return; // 로그인 안 되어 있으면 여기서 스크립트 종료
    }

    // 초기 좋아요 상태에 따라 버튼 클래스 설정
    function updateButtonAppearance(isLiked) {
        if (isLiked) {
            likeButton.classList.add('liked'); // CSS로 색상/아이콘 변경
            document.getElementById('like-text').textContent = '좋아요 취소';
        } else {
            likeButton.classList.remove('liked');
            document.getElementById('like-text').textContent = '좋아요';
        }
    }

    // 초기 상태 반영
    let isLiked = likeButton.dataset.isLiked === 'true';
    updateButtonAppearance(isLiked);


    // 로그인 상태일 때, 좋아요 버튼 클릭 이벤트 핸들러
    likeButton.addEventListener('click', async function() {
        try {
            // 버튼 비활성화 (중복 클릭 방지)
            likeButton.disabled = true;
            
            // 서버에 좋아요 요청 (POST)
            const response = await fetch(`/api/posts/${postId}/like`, {
                method: 'POST',
                headers: {
                    'Content-Type': 'application/json',
                    // CSRF 토큰 등 필요한 인증 정보 포함
                }
            });

            if (!response.ok) {
                throw new Error(`HTTP error! status: ${response.status}`);
            }

            const data = await response.json();

            if (data.success) {
                // 1. 좋아요 개수 업데이트
                likeCountSpan.textContent = data.current_likes;
                
                // 2. 버튼 상태 업데이트
                isLiked = data.is_liked;
                updateButtonAppearance(isLiked);
            }

        } catch (error) {
            console.error('좋아요 처리 중 오류 발생:', error);
            alert('좋아요 처리 중 오류가 발생했습니다. 다시 시도해 주세요.');
        } finally {
            // 버튼 활성화
            likeButton.disabled = false;
        }
    });
});
```

## 💡 추가 고려 사항
### 1. 보안: CSRF 보호
**CSRF (Cross-Site Request Forgery)** 공격을 방지하기 위해, POST 요청을 보낼 때 **CSRF 토큰**을 반드시 포함해야 합니다. 대부분의 웹 프레임워크는 이를 위한 기능을 제공합니다 (예: Django의 `{% csrf_token %}`, 토큰을 HTTP 헤더에 담는 방식 등).
### 2. 데이터베이스 설계
좋아요 기능을 위해 최소한 다음 정보를 저장하는 테이블이 필요합니다.

| **필드** | **설명** |
| --- | --- |
| `id` | PK (기본 키) |
| `post_id` | 어떤 게시글에 좋아요를 눌렀는지 (FK) |
| `user_id` | 누가 좋아요를 눌렀는지 (FK) |
| `created_at` | 좋아요를 누른 시점 |

이 테이블에 **`post_id`****와 ****`user_id`****의 조합이 유일함**을 보장하는 **Unique Constraint**를 설정하여 사용자가 한 게시글에 여러 번 좋아요를 누르는 것을 방지합니다.
