## 💡 HTML (웹 화면의 구조)

| 항목 | 핵심 내용 |
| --- | --- |
| **마크업 & 태그** | HTML은 **마크업** 언어이며, \$`< >`\$로 감싸 컴퓨터에 의미를 전달하는 것이 **태그**입니다. |
| **엘리먼트** | 여는 태그, 닫는 태그, 내용물 전체를 \*\*요소(Element)\*\*라고 합니다. |
| **자체 닫는 태그** | ‘\<br\>‘(줄 바꿈)처럼 닫는 태그가 없으며, 자식을 가질 수 없습니다. |
| **하이퍼링크** | \$`<a href="주소">...</a>`는주소로이동하는기능(`target="_blank"`\$는 새 창에서 열기)을 가집니다. |
| **블록 요소의 특징** | **너비**는 최대한 늘어나고, **높이**는 최소한으로 줄어듭니다. **한 줄을 혼자** 사용합니다. (`<div>`, `<section>`, `<nav>`, `<article>`의 기본값) |
| **`inline-block`****의 특징** | **너비/높이** 모두 최소한으로 줄어듭니다. **한 줄에 최대한 여럿이** 나옵니다. |
| **공백** | HTML에서는 공백을 두 칸 이상 연속으로 표시하려면 \*\*`&nbsp;`\*\*를 사용해야 합니다. |

## 🎨 CSS (웹 화면의 스타일)

| 항목 | 핵심 내용 |  |
| --- | --- | --- |
| **역할** | HTML 요소를 찾아가서 미리 정의된 스타일을 부여합니다. |  |
| **우선순위** | **선택자가 상세할수록** 적용 우선순위가 높습니다. |  |
| **노말라이즈/리셋** | 브라우저별 기본 스타일 차이를 없애는 작업입니다. |  |
| **`display`**** 속성 예외** | ‘\<a\>‘, \$`<span>`\$는 기본 `inline`입니다. \$`<img>`\$는 기본 `inline-block`입니다. |  |

### 🔍 CSS 선택자 정리

| 선택자 | 이름 | 설명 | 예시 |
| --- | --- | --- | --- |
| `div > div` | **자식 선택자** | 바로 아래 한 단계 자식만 선택합니다. |  |
| `div div` | **후손 선택자** | 모든 하위(자손) 요소를 선택합니다. |  |
| `section + nav` | **인접 형제 선택자** | ‘\<section\>‘ 바로 다음에 오는 **하나의 형제** \$`<nav>`\$를 선택합니다. |  |
| `nav ~ nav` | **일반 형제 선택자** | ‘\<nav\>‘ 뒤에 나오는 **모든 형제** \$`<nav>`\$를 선택합니다. |  |

### 텍스트 및 색상 속성

| 속성 | 설명 | 코드 예시 |
| --- | --- | --- |
| **`color`** | 글자 색상. `rgb(r, g, b)`, `rgba(r, g, b, 투명도)`, `#헥사코드` 사용 가능. | `color: #787878;` |
| **`opacity`** | 요소 전체의 투명도 조절 (0\~1). | `opacity: 0.5;` |
| **`font-size`** | 글자 크기. `3rem` (기본 폰트 크기의 3배), `140px` 등. | `font-size: 3rem;` |
| **`font-weight`** | 글자 두께. `bold` 또는 `normal`. | `font-weight: bold;` |
| **`text-decoration`** | 글자 장식. 링크 밑줄 제거 시 **`none`** 사용. | `text-decoration: none;` |
| **`letter-spacing`** | 글자 사이의 간격(자간) 조절. | `letter-spacing: -10px;` |
| **`text-align`** | 블록 요소 안의 **텍스트**나 **`inline-block`**** 요소**를 정렬합니다. | `text-align: center;` |

## 💻 HTML & CSS 학습 개념 정리 (예시 포함)
### 1. 개념 - HTML, CSS, JS 개요
- **HTML:** 웹 화면을 구성하는 요소 (역할: **배우**).
- **CSS:** 구성된 화면(HTML)을 꾸미는 역할 (역할: **스타일리스트**).
- **태그:** 컴퓨터에게 알려주기 위함. `< >`와 `</ >` 한 쌍이 기본.
- **마크업:** 태그를 이용해 구조화하는 행위.
- **Element (요소):** 태그와 내용물을 포함한 전체.
HTML
```html
<div>배우</div>

<style>
/* 스타일리스트 */
div {
    color:red;
}
</style>
```
### 2. 개념 - HTML, CSS, JS 개요 2 (선택자 상세도)
- **선택자 상세도:** 선택자가 **상세할수록** 스타일 적용의 **우선순위**가 높아집니다.
- **기본 구조 요소:** `div`, `article`, `section`, `nav` (4가지)
HTML
```html
<subject>안녕하세요. 소개합니다.</subject>
<content>반갑습니다. 저는 26살, 홍길동 입니다.</content>

<style>
/* CSS */
subject {
    color:red;
    background-color:blue;
}
content {
    color:blue;
    background-color:gold;
}
</style>
```
### 3. 개념 - display 속성 정리
요소의 **너비, 높이, 줄 사용 방식**을 결정하는 가장 중요한 속성입니다.

| 종류 | 특징 | 너비/높이 (설정 없을 시) | Line 사용 | 정렬 | 예외 |
| --- | --- | --- | --- | --- | --- |
| **inline-block, inline-flex** | 본질: **글자화** | **최소한으로 줄어듦** | 한 줄에 **최대한 여러 개** | 부모의 `text-align`에 의해 정렬 | `img`는 기본 `inline-block` |
| **block, flex** | 본질: **블록화** | **최대한으로 넓어짐** | 한 줄을 **무조건 혼자 씀** | `margin-left/right: auto`로 스스로 정렬 | `div` 등은 기본 `block` |
| **inline** | 본질: **글자화** | **최소한으로 줄어듦** | 한 줄에 **최대한 여러 개** | 부모의 `text-align`에 의해 정렬 | `a`, `span`은 기본 `inline` (`width/height/상하 margin/padding` 적용 불가) |

### 4. 개념 - 엘리먼트(배우)의 부모, 자식, 형제관계
- **부모 엘리먼트:** 나를 감싸는 엘리먼트.
- **자식 엘리먼트:** 내가 감싸는 엘리먼트.
- **형제 엘리먼트:** 같은 부모를 둔 엘리먼트.
HTML
```html
<div>
    <nav></nav> <nav></nav> </div>
```
### 5. 개념 - 글자 (Text 속성)
글자의 스타일을 지정하는 속성들입니다.

| 속성 | 설명 | 코드 예시 |
| --- | --- | --- |
| **`color`** | 글자 색상. `rgb(r,g,b)`, `rgba(r,g,b,alpha:0~1)`, `#헥사코드` 사용. (0\~255 값 3칸 필요) | `color:rgba(255,0,0,0.5);` |
| **`opacity`** | 요소 전체의 투명도 조절 (0\~1). |  |
| **`font-weight`** | 글자의 두께 조절 (`bold`, `normal`). | `font-weight:bold;` |
| **`font-size`** | 글자의 크기 (`3rem`, `140px`). | `font-size:3rem;` |
| **`letter-spacing`** | 글자(자간) 사이의 간격 조절. | `letter-spacing:100px;` |
| **그라데이션** | 배경에 적용 가능하며, 컬러피커를 이용해 색상 선택 가능. |  |

CSS
```css
/* 글자 스타일 예시 */
div {
    font-weight:bold; 
    font-size:3rem;
    letter-spacing:-10px;
    color:#787878;
}
section {
    font-size:10rem;
    color:rgba(255,0,0,0.5); /* 투명도 0.5 적용 */
}
```
### 6. 개념 - a와 br (링크 및 줄 바꿈)
- `<a>` 태그는 **하이퍼 링크** 기능을 실행하며, `target="_blank"` 속성은 새 창으로 띄울지 여부를 정합니다.
- `<br>` 태그는 **셀프 클로즈 태그**이며, 줄 바꿈 기능을 합니다.
HTML
```html
<a href="https://to2.kr/bTn">bmx</a>
<br>
<br>
<a href="http://www.naver.com/" target="_blank">네이버</a>

<style>
a {
    background-color:red;
}
</style>
```
### 7. 개념 - 후손 선택자 (` `)
-  (공백)을 사용하여 **후손** 엘리먼트(자식, 손자 등 모든 하위 요소)를 선택합니다.
- `>`는 **자식** 선택자이며, 특정 상황에서는 후손 선택자와 동일한 결과를 낼 수 있습니다.
HTML
```html
<div> <a href="#">네이버</a> </div>
<section>
    <a href="#">구글</a> </section>

<style>
/* section 엘리먼트 안에 들어있는 a (후손/자식 선택자가 적용됨) */
section a { 
    color:red;
}

/* 선택자가 덜 상세하므로 무시됨 */
a {
    color:pink; 
}
/* 선택자가 길면 우선순위가 높습니다. */
a { 
    color:green; /* 이 CSS가 적용됨 */
}
</style>
```
### 8. 개념 - text-align
- **절대로 자신을 정렬하는 것이 아니라**, **자신이 가지고 있는 텍스트**를 정렬합니다.
- `display:inline-block`을 적용하면 엘리먼트가 \*\*'텍스트화'\*\*되어 `text-align`으로 정렬이 가능해집니다.
HTML
```html
<div>안녕하세요.</div>
<section>잘가세요.</section>
<nav>또 봐요</nav>

<style>
div {
    text-align:left; /* 텍스트를 왼쪽 정렬 */
}
section {
    text-align:center; /* 텍스트를 가운데 정렬 */
}
nav {
    text-align:right; /* 텍스트 또는 inline-block 요소를 오른쪽 정렬 */
}
</style>
```
### 9. 개념 - text-align v2 (엘리먼트 정렬)
`text-align`은 `inline-block` 요소까지 정렬할 수 있음을 보여주는 예시입니다.
HTML
```html
<div>
    <a href="http://www.naver.com" target="_blank">네이버로 이동</a>
</div>
<section>
    <a href="http://www.google.com" target="_blank">구글로 이동</a>
    <a href="http://www.google.com" target="_blank">구글로 이동</a>
    <article></article>
</section>

<style>
section {
    text-align:center; /* section 안의 a와 article이 중앙 정렬됨 */
}
nav {
    text-align:right; /* nav 안의 a가 오른쪽 정렬됨 */
}
section article {
    width:200px; 
    height:200px;
    background-color:blue;
}
a {
    background-color:gold;
}
</style>
```

### 10. 개념 - hover
- `:`를 사용하여 **마우스 올림**을 받았을 때(‘:hover‘)의 스타일을 지정합니다.
HTML
```html
<div></div>

<style>
/* 그냥 div */
div {
    width:100px;
    height:100px;
    background-color:red;
}
/* 마우스 올림을 받은 div */
div:hover {
    background-color:blue;
}
</style>
```
### 11. 개념 - short code (Emmet/젠코딩)
- **`>`** : **자식 선택자**를 HTML 생성 시 사용합니다. (`div>section*2>nav` 입력 후 Tab 키)
- **`+`** : **인접 동생 선택자**를 HTML 생성 시 사용합니다. (`div+section` 입력 후 Tab 키)
### 12. 개념 - 및 text-decoration:none
- **`&nbsp;`**: **공백 한 칸**을 의미하며, 두 칸 이상 띄울 때 사용합니다.
- **`text-decoration:none`**: 글자의 장식(예: 링크의 기본 밑줄)을 **제거**합니다.
HTML
```html
안&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;녕
<br>
잘&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;가
<hr>
하&nbsp;&nbsp;늘

<div>
    <a href="#">안녕</a>
</div>

<style>
div > a {
    text-decoration:none; /* 글자의 효과 제거 */
}
</style>
```
