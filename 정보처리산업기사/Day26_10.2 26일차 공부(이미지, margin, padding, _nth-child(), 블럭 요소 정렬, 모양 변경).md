## 1. 이미지 태그 (`<img>`)와 특이점
### 이미지 태그의 기본 구조
HTML에서 이미지를 삽입할 때 사용하며, 닫는 태그가 없는 **단일 태그**입니다. 자식 요소를 가질 수 없습니다.

| 속성 | 설명 |
| --- | --- |
| `src` | 이미지 **소스 경로**(URL)를 지정합니다. |
| `alt` | 이미지를 불러오지 못했을 때 표시되는 **대체 텍스트**입니다. 시각 장애인을 위한 스크린 리더기에도 사용됩니다. |

HTML
```html
<img src="https://picsum.photos/id/237/480/480" alt="강아지 이미지">
```

### 이미지의 특이점 (비율 유지)
이미지는 고유한 가로-세로 \*\*비율(Aspect Ratio)\*\*을 가지고 있습니다. CSS로 너비(`width`)와 높이(`height`)를 모두 설정하고 비율이 맞지 않으면 이미지가 찌그러지며 비율이 깨집니다.
하지만 **너비나 높이 중 한쪽만** 설정하면, 나머지 한쪽은 고유 비율에 맞춰 **자동으로** 설정됩니다.

## 2. 여백 설정: 마진 (`margin`)과 패딩 (`padding`)
### 마진 (`margin`)
요소의 **바깥쪽 여백**을 설정합니다. 다른 요소와의 간격을 조절합니다.
- `margin-top`, `margin-right`, `margin-bottom`, `margin-left`를 개별 설정하거나, `margin` 속성으로 한 번에 설정할 수 있습니다.
- 값을 하나만 주면 **상하좌우** 모두 적용됩니다.
- 값을 두 개 주면 **(상하), (좌우)** 순서로 적용됩니다.
- `margin-left: auto;`와 `margin-right: auto;`를 함께 사용하면 **블록 요소**를 부모 요소 내에서 **가운데** 정렬할 수 있습니다.
### 패딩 (`padding`)
요소의 **안쪽 여백**을 설정합니다. 콘텐츠(내용)와 테두리(border) 사이의 간격을 조절합니다.
- `padding-top`, `padding-right`, `padding-bottom`, `padding-left`를 개별 설정하거나, `padding` 속성으로 한 번에 설정할 수 있습니다.
- `margin`과 마찬가지로 값을 하나만 주면 **상하좌우** 모두, 두 개 주면 **(상하), (좌우)** 순서로 적용됩니다.
### 마진/패딩 기본 예시
HTML
```html
<div>Lorem ipsum dolor sit amet...</div>
<div>Vel animi doloremque maxime...</div>
```

CSS
```css
/* CSS */
div {
    width: 300px;
    height: 300px;
    background-color: red;
    display: inline-block; /* 한 줄에 여러 개 배치 */

    /* 박스의 바깥쪽 여백 (상하좌우 모두 10px) */
    margin: 10px;

    /* 박스의 안쪽 여백 (상하좌우 모두 10px) */
    padding: 10px;
}
```

## 3. `display` 속성과 여백의 관계
### `display:inline` 요소의 특징
`<img>`, `<a>`, `<span>` 등 기본적으로 `display:inline` 속성을 가지는 요소에는 `width`, `height` 속성이 적용되지 않으며, `margin-top`, `margin-bottom`, `padding-top`, `padding-bottom` 등 **수직 방향**의 여백 속성도 시각적으로 제대로 작동하지 않거나 다른 요소에 영향을 주지 않습니다.
- **수평 방향** 여백 (`margin-left`, `margin-right`, `padding-left`, `padding-right`)은 적용됩니다.
### `display:inline-block` 요소의 특징
`inline`처럼 한 줄에 배치되지만, **`width`****, ****`height`****, ****`margin`****, ****`padding`**** 속성이 모두 정상적으로 작동**합니다.
HTML
```html
<section>
    <a href="#">안녕</a>
    <a href="#">잘가</a>
</section>

<div>
    <a href="#">안녕</a>
    <a href="#">잘가</a>
</div>
```

CSS
```css
/* CSS */
a {
    background-color: red;
    width: 100px;
    padding: 10px; /* 수평 패딩은 inline에서도 작동 */
}

/* section 안의 a는 display:inline-block이므로 width, height, 모든 padding/margin 작동 */
section > a {
    display: inline-block;
}

/* div 안의 a는 기본값 display:inline이므로 width, height 미작동, 수직 padding/margin 미작동 */
/* 하지만 위 CSS에서 a에 적용된 width와 수직 padding은 작동하지 않습니다. */
```

## 4. 요소 선택자 심화: `nth-child` 및 ID/Class
### 자식 요소 선택자 (`:nth-child`)
부모 요소의 자식 중 특정 순서에 있는 요소를 선택합니다.

| 선택자 | 설명 |
| --- | --- |
| `:first-child` | 첫 번째 자식 요소를 선택합니다. |
| `:last-child` | 마지막 자식 요소를 선택합니다. |
| `:nth-child(n)` | 앞에서부터 n번째 자식 요소를 선택합니다. |
| `:nth-last-child(n)` | 뒤에서부터 n번째 자식 요소를 선택합니다. |
| `:nth-child(5n + 1)` | 5의 배수 + 1 번째 자식 (1,6,11,…)을 선택합니다. |

CSS
```css
/* CSS 예시 */
div:first-child {
    background-color: blue; /* 첫 번째 div */
}

div:nth-child(2) {
    background-color: gold; /* 두 번째 div */
}

section > :nth-child(5n + 1) {
    background-color: gold; /* 1, 6, 11, ... 번째 자식 요소 */
}
```

### 클래스 (`.class`)와 ID (`#id`)

| 속성 | 설명 | CSS 선택자 | 비고 |
| --- | --- | --- | --- |
| `class` | 여러 요소에 같은 이름을 지정하여 스타일링하며, **중복 사용 가능**합니다. 하나의 요소에 여러 클래스 지정 가능 (`class="a b"`). | `.a` |  |
| `id` | 문서 내에서 **유일한 이름**으로 지정해야 하며, 하나의 요소에 하나만 지정합니다. | `#a` |  |

HTML
```html
<div class="a">1</div>
<div id="a">2</div>
<div class="a">3</div>
<div class="a b">4</div>
<section class="a b">5</section>
```

CSS
```css
/* CSS */
.a {
    color: red; /* class가 a인 모든 요소 */
}

#a {
    color: blue; /* id가 a인 요소 (원칙적으로 하나) */
}

.a.b {
    color: gold; /* class a와 b를 동시에 가진 요소 */
}

section.a.b {
    color: green; /* 태그가 section이고 class a와 b를 동시에 가진 요소 */
}
```

## 5. 블록 요소의 정렬
**블록 요소** (예: `<div>`, `<h1>`, 단독으로 배치된 `<img>` 등)를 가로 방향으로 정렬하는 방법입니다.
- 블록 요소는 기본적으로 너비가 부모 요소를 가득 채우므로, 정렬을 위해선 **너비(****`width`****)를 지정**해야 합니다.

| 정렬 | CSS 속성 |
| --- | --- |
| **좌측 정렬** | `margin-left: 0;` (기본값) |
| **가운데 정렬** | `margin-left: auto; margin-right: auto;` |
| **우측 정렬** | `margin-left: auto; margin-right: 0;` |

CSS
```css
/* CSS */
div {
    width: 100px;
    height: 100px;
    background-color: red;
}

/* 두 번째 div: 가운데 정렬 */
div:nth-child(2) {
    background-color: gold;
    margin-left: auto;
    margin-right: auto;
}

/* 세 번째 div: 우측 정렬 */
div:nth-child(3) {
    background-color: green;
    margin-left: auto;
}
```

## 6. 모서리 둥글게 깎기 (`border-radius`)
### `border-radius`
요소의 네 모서리를 둥글게 처리합니다.
- 값을 **px**로 지정하면 둥글게 깎이는 정도를 픽셀 단위로 설정합니다.
- 값을 \*\*%\*\*로 지정하면 요소의 크기 대비 백분율로 설정합니다.
	- \*50%\*\*를 주면 너비와 높이가 같을 때 완벽한 원을 만들 수 있습니다.
CSS
```css
/* CSS */
/* 50px만큼 둥글게 */
div {
    border-radius: 50px;
}

/* 완벽한 원 또는 타원형 만들기 */
div {
    width: 200px;
    height: 200px;
    border-radius: 50%; /* 너비, 높이의 50%만큼 둥글게 처리하여 원 모양 */
}
```

## 7. 상속 (`inherit`)과 노말라이즈 (초기화)
### 상속 (`inherit`)
일부 CSS 속성(예: `color`, `font-family`, `font-size` 등 텍스트 관련 속성)은 부모 요소에 적용된 값이 자식 요소에게 자동으로 전달됩니다. 이를 **상속**이라고 합니다.
`inherit` 키워드를 사용하면, 기본적으로 상속되지 않는 속성(예: `border`)이라도 부모 요소의 값을 **따라가도록** 명시할 수 있습니다.
CSS
```css
/* CSS */
body {
    color: red;
    border: 10px solid green; /* border는 기본적으로 상속되지 않음 */
}

section {
    /* border:inherit; 을 사용하면 section은 body의 border 속성을 따라하여 초록색 10px 테두리가 적용됨 */
    border: inherit;
    color: blue; /* color는 기본적으로 상속되지만, 덮어씀 */
}
```

### 노말라이즈 (Normalize)
웹 브라우저마다 기본적으로 적용하는 스타일(예: `margin`, `padding`, `<a>` 태그의 색상/밑줄 등)이 다릅니다. 이 기본 스타일을 재정의하여 모든 브라우저에서 **동일한 환경**에서 시작하도록 초기화하는 작업을 **노말라이즈**라고 합니다.

| 대상 | 노말라이즈 예시 | 설명 |
| --- | --- | --- |
| `<a>` 태그 | `a { color: inherit; text-decoration: none; }` | 텍스트 색상을 부모로부터 상속받고, 기본 밑줄을 제거합니다. |
| `<body>` | `body { margin: 0; padding: 0; }` | 브라우저가 기본으로 부여하는 외부 여백을 제거하여 콘텐츠를 페이지 끝에 붙입니다. |

CSS
```css
/* CSS - a 노말라이즈 */
a {
    color: inherit; /* 부모 요소의 글자색을 따라감 */
    text-decoration: none; /* 밑줄 제거 */
}

/* CSS - body 노말라이즈 */
body {
    margin: 0; /* 브라우저 기본 margin 제거 */
}
```
