## 1. CSS 애니메이션 관련 속성

| **속성** | **설명** |
| --- | --- |
| **`transition`** | CSS 속성 값이 **변화할 때** 그 변화를 부드럽게(시간을 들여) 만들어주는 속성입니다. `transition: [속성명] [지속 시간] [타이밍 함수] [딜레이];` 형태로 사용하며, `[속성명]`을 명시하지 않으면 모든 속성에 적용됩니다. |

### 예시: 색상과 너비 변화에 `transition` 적용
`transition`은 **변화가 일어나는 요소(여기서는 ****`div`****) 자체**에 정의되어야 변화를 감지하고 부드럽게 만들어 줍니다.
**HTML:**
```html
HTML

`<div class="box">마우스를 올려보세요</div>`
```

**CSS:**
```css
CSS

`.box {
    width: 200px;
    height: 100px;
    background-color: blue;
    /* 변화를 감지하고 부드럽게 만들 속성을 .box 자체에 적용 */
    transition: width 5s, background-color 3s; 
    /* 또는 transition: all 5s; */
}

.box:hover {
    /* 변화가 일어날 속성 값 */
    width: 50%;
    background-color: red;
}`
```

## 2. 가상 요소 (`::after`)

| **속성** | **설명** |
| --- | --- |
| **`::after`** | 선택한 요소의 **내용(content)** 뒤에 가상의 콘텐츠를 생성합니다. 반드시 **`content`**** 속성**과 함께 사용해야 하며, 실제로 HTML 문서에는 존재하지 않기 때문에 스타일링에 유용합니다. |

### 예시: `div` 뒤에 텍스트 추가
**HTML:**
```html
HTML

`<div class="after-box">원본 내용</div>`
```

**CSS:**
```css
CSS

`.after-box {
    border: 1px solid black;
    padding: 10px;
}

.after-box::after {
    /* 필수 속성: 추가할 내용 */
    content: " test"; 
    /* 가상 요소 스타일링 */
    color: green;
    font-weight: bold;
}`
```

## 3. 레이아웃 관련 속성 (float, clear, overflow)

| **속성** | **설명** |
| --- | --- |
| **`float`** | 요소를 일반적인 문서 흐름에서 **띄워서** 왼쪽(`left`) 또는 오른쪽(`right`)으로 배치합니다. 주로 이미지 주변에 텍스트를 감싸거나, 가로 방향 레이아웃을 만들 때 사용했으나, 현재는 **Flexbox**나 **Grid** 사용이 권장됩니다. |
| **`clear`** | `float`된 요소 옆에 배치되는 것을 방지합니다. `clear: both;`는 양쪽(`left` 또는 `right`)에 띄워진 요소의 영향을 받지 않고 다음 줄에 배치되도록 합니다. |
| **`overflow`** | 요소의 내용이 컨테이너를 **벗어났을 때** 처리 방식을 지정합니다. `hidden`을 사용하면 넘치는 내용을 잘라내고, **플로팅(float)된 자식 요소**가 부모의 높이를 벗어날 때 부모가 높이를 인식하도록 하는 **'Float Clear' 핵**으로도 사용됩니다. |

### 예시: float와 clear, overflow: hidden 활용
**HTML:**
```html
HTML

`<div class="container">
    <div class="floated-item">Float</div>
</div>
<div class="cleared-item">Clear: Both</div>`
```

**CSS:**
```css
CSS
.floated-item {
    float: left; /* 왼쪽으로 띄우기 */
    width: 100px;
    height: 100px;
    background-color: orange;
    margin-right: 10px;
}

.container {
    background-color: #eee;
    /* (Clear Fix 핵) 자식(floated-item)이 float 되어 높이가 0이 되는 것을 방지 */
    overflow: hidden; 
    padding: 10px;
}

.cleared-item {
    /* floated-item의 영향을 받지 않고 새로운 줄에 배치 */
    clear: both; 
    background-color: purple;
    color: white;
    padding: 10px;
}
```

## 4. 투명도 조절 속성

| **속성** | **설명** |
| --- | --- |
| **`opacity`** | 요소의 **투명도**를 설정합니다. 값은 \*\*0 (완전히 투명)\*\*부터 **1 (완전히 불투명)** 사이의 숫자로 표현됩니다. **요소 전체** (내용, 배경, 테두리 등 모두 포함)에 적용됩니다. |

### 예시: 투명도 조절
**HTML:**
```html
HTML

`<div class="transparent-box">투명도 0.5</div>`
```

**CSS:**
```css
CSS

`.transparent-box {
    width: 150px;
    height: 70px;
    background-color: green;
    color: white;
    /* 50% 투명하게 설정 */
    opacity: 0.5; 
}`
```

## 5. Flexbox (Flexible Box Layout)

| **속성** | **설명** |
| --- | --- |
| **`flex`** | 1차원 레이아웃(가로나 세로 중 하나)을 효율적으로 구성하기 위한 CSS 모듈입니다. 부모 요소에 \*\*`display: flex;`\*\*를 선언하여 컨테이너를 만들고, 자식 요소(아이템)들의 공간 분배, 정렬, 순서 등을 유연하게 제어합니다. 현대 웹 레이아웃의 가장 기본적인 방법입니다. |

### 예시: Flexbox를 이용한 가로 정렬 및 중앙 배치
**HTML:**
```html
HTML

`<div class="flex-container">
    <div class="flex-item">1</div>
    <div class="flex-item">2</div>
    <div class="flex-item">3</div>
</div>`
```

**CSS:**
```css
CSS

`.flex-container {
    display: flex; /* Flex 컨테이너 선언 */
    height: 150px;
    background-color: lightblue;
    border: 1px solid blue;
    
    /* 아이템들을 가로 중앙으로 정렬 */
    justify-content: center; 
    /* 아이템들을 세로 중앙으로 정렬 */
    align-items: center;    
}

.flex-item {
    width: 50px;
    height: 50px;
    background-color: royalblue;
    color: white;
    margin: 5px;
    text-align: center;
    line-height: 50px;
}`
```
