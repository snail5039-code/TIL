
### 2. DTO (Data Transfer Object)
스프링 부트는 동일한 `name`으로 넘어온 여러 값들을 \*\*`List`나 `String[]` (배열)\*\*로 자동 매핑해줍니다.
Java

```javascript
import lombok.Data;
import java.util.List;

@Data
public class UserInterestDTO {
    private String userName;
    
    // 체크박스 값들을 받을 리스트
    // 체크된 값이 없으면 null이 들어올 수 있으니 주의해야 합니다.
    private List<String> hobbies; 
}
```

### 3. Controller
컨트롤러는 평소와 동일하게 DTO를 받으면 됩니다. 스프링이 알아서 리스트에 값을 채워줍니다.
Java

```javascript
@Controller
public class InterestController {

    @Autowired
    private InterestService interestService;

    @PostMapping("/save-hobbies")
    public String saveHobbies(UserInterestDTO userInterestDTO) {
        // 체크박스 선택 안 했을 경우 null 처리 (선택사항)
        if (userInterestDTO.getHobbies() != null) {
            interestService.saveHobbies(userInterestDTO);
        }
        return "redirect:/result";
    }
}
```

### 4. MyBatis (Service & Mapper)
여기서 DB 설계에 따라 두 가지 방식이 나뉩니다. 상황에 맞는 방법을 선택하세요.
### 방식 A: 정석적인 방법 (1:N 관계 테이블에 저장)
데이터 정규화를 위해 별도의 매핑 테이블(예: `user_hobby`)에 여러 행(Row)을 `INSERT` 하는 방식입니다. MyBatis의 `<foreach>`를 사용합니다.
**Service**
Java
```javascript
public void saveHobbies(UserInterestDTO dto) {
    // MyBatis 매퍼 호출
    interestMapper.insertHobbies(dto);
}
```

**Mapper Interface**
Java
```javascript
@Mapper
public interface InterestMapper {
    void insertHobbies(UserInterestDTO dto);
}
```

**Mapper XML (핵심)**`collection`에 DTO의 리스트 변수명을 적습니다.
XML
```javascript
<insert id="insertHobbies" parameterType="com.example.demo.dto.UserInterestDTO">
    INSERT INTO user_hobby_table (
        user_name, 
        hobby_code
    )
    VALUES
    <foreach collection="hobbies" item="item" separator=",">
        (
            #{userName},
            #{item}
        )
    </foreach>
</insert>
```

> 설명: 사용자가 '코딩', '운동'을 선택하면, 쿼리는 INSERT INTO ... VALUES ('홍길동', 'coding'), ('홍길동', 'fitness') 처럼 변환되어 한 번에 실행됩니다.

---

### 방식 B: 간편한 방법 (문자열로 합쳐서 저장)
검색 기능이 중요하지 않고 단순히 저장/출력만 한다면, 콤마(`,`)로 구분된 문자열 하나로 만들어 저장하기도 합니다.
**Service (Java에서 가공)**
Java
```javascript
public void saveHobbies(UserInterestDTO dto) {
    List<String> list = dto.getHobbies();
    
    // ["coding", "fitness"] -> "coding,fitness" 문자열로 변환
    String joinedString = String.join(",", list);
    
    // 변환된 문자열을 매퍼에 전달
    interestMapper.insertHobbyString(dto.getUserName(), joinedString);
}
```

**Mapper XML**
XML
```javascript
<insert id="insertHobbyString">
    INSERT INTO user_info (user_name, hobby_list)
    VALUES (#{userName}, #{joinedString})
</insert>
```

### 5. 추가적인 팁과 주의사항
### 1. 아무것도 선택하지 않았을 때 (Null Safety)
체크박스를 하나도 체크하지 않고 전송하면, `hobbies` 리스트는 비어있는 리스트(`[]`)가 아니라 \*\*`null`\*\*이 됩니다.
- **해결:** Service 단에서 `if (dto.getHobbies() == null)` 체크를 하거나, DTO에서 초기화를 해두는 것이 안전합니다.Java
	`private List<String> hobbies = new ArrayList<>(); // 기본값 초기화`
### 2. 수정(Update) 로직 처리
체크박스 수정 로직은 조금 까다롭습니다. (예: 코딩, 운동 -\> 독서로 변경 시)
- **가장 쉬운 방법:** 기존 데이터를 **모두 삭제(DELETE)** 하고, 체크된 새 데이터를 **다시 입력(INSERT)** 하는 방식이 구현하기 가장 깔끔합니다.Java
	
	```javascript
@Transactional
public void updateHobbies(UserInterestDTO dto) {
    mapper.deleteHobbiesByUserName(dto.getUserName()); // 기존 것 삭제
    if(dto.getHobbies() != null && !dto.getHobbies().isEmpty()){
        mapper.insertHobbies(dto); // 새 리스트 입력
    }
}
	```
### 3. Thymeleaf에서 '체크된 상태'로 보여주기 (수정 화면)
DB에서 가져온 값과 비교하여 체크박스에 `checked` 속성을 넣어줘야 합니다. Thymeleaf는 이를 쉽게 처리해줍니다.
HTML
```javascript
<div th:each="hobby : ${allHobbies}">
    <input type="checkbox" 
           name="hobbies" 
           th:value="${hobby.code}" 
           th:checked="${#lists.contains(user.hobbies, hobby.code)}" />
    <label th:text="${hobby.name}"></label>
</div>
```

**요약하자면:**
1. HTML `name`을 통일한다.
2. DTO에서 `List` 자료형으로 받는다.
3. MyBatis XML에서 `<foreach>`를 사용해 다중 INSERT를 수행한다.
