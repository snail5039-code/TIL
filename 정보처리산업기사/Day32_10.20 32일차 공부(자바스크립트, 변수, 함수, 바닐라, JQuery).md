### 2. 변수 선언과 데이터 타입
자바스크립트는 변수 선언 시 **데이터 타입에 대한 제약이 없습니다** (동적 타입). 변수 선언에 사용되는 예약어는 `var`, `let`, `const`가 있습니다.

| **예약어** | **특징** | **재할당 가능 여부** |
| --- | --- | --- |
| **var** | 함수 스코프, **호이스팅** 시 `undefined`로 초기화. (최신 JS에서 사용 지양) | 가능 |
| **let** | 블록 스코프, **호이스팅** 되지만 초기화되기 전 사용 불가 (TDZ). | 가능 |
| **const** | 블록 스코프, 선언과 동시에 초기화해야 하며, **상수**로 사용. | **불가** (재할당) |

JavaScript
```javascript
// let과 const는 블록 스코프를 따릅니다.
let changeable = 10;
const constantValue = '상수';

changeable = 20; // let은 재할당 가능
// constantValue = '새 값'; // const는 재할당 시 에러 발생

console.log(changeable); // 20
console.log(constantValue); // 상수
```

### 3. 함수 선언 방식
### 3.1. 함수 선언식 (Function Declaration)
JavaScript
```javascript
function b() {
  console.log('함수 선언식: test');
}
b(); // 호이스팅으로 인해 선언 위치와 관계없이 호출 가능
```

### 3.2. 함수 표현식 (Function Expression)
JavaScript
```javascript
let a = function() {
  console.log('함수 표현식: test');
};
a(); // 변수에 할당된 후에만 호출 가능
```

### 3.3. 화살표 함수 (Arrow Function)
`function` 키워드 대신 `=>`를 사용하며, 특히 **`this`**** 바인딩 방식**이 다릅니다 (자세한 내용은 \[5. 콜백 함수와 이벤트 리스너\] 참조).
JavaScript
```javascript
const c = () => {
  console.log('화살표 함수: test');
};
c();
```

### 4. 배열 순회
배열 `let a = [10, 20, 30];`을 순회하는 두 가지 일반적인 방법입니다.
### 4.1. `for` 반복문
JavaScript
```javascript
for(let i = 0; i < a.length; i++){
  console.log(`for문: ${a[i]}`); // for문: 10, for문: 20, for문: 30
}
```

### 4.2. `forEach` 메서드 (콜백 함수 사용)
JavaScript
```javascript
a.forEach(function(value){
  console.log(`forEach: ${value}`); // forEach: 10, forEach: 20, forEach: 30
});
```

### 5. 콜백 함수와 이벤트 리스너
**콜백 함수**는 다른 함수의 인수로 전달되어 특정 시점에 실행되는 함수입니다. 웹 개발에서는 주로 이벤트 처리(Event Handling)에 사용됩니다.
### HTML 및 CSS 예시
HTML
```html
<!DOCTYPE html>
<html>
<head>
<style>
  div {
    width: 100px;
    height: 50px;
    background-color: lightblue;
    border: 1px solid blue;
    cursor: pointer;
    text-align: center;
    line-height: 50px;
  }
</style>
</head>
<body>
  <div id="myDiv">클릭하세요</div>
  <script>
    // 자바스크립트 코드
    document.querySelector('#myDiv').addEventListener('click', function() {
      console.log('일반 콜백 함수: div가 클릭되었습니다.');
    });

    document.querySelector('#myDiv').addEventListener('click', () => {
      console.log('화살표 함수 콜백: div가 클릭되었습니다.');
    });
  </script>
</body>
</html>
```

## 💡 jQuery의 `this` 키워드 정리
**jQuery**는 자바스크립트 라이브러리로, DOM 조작과 이벤트 처리를 쉽게 해줍니다. jQuery의 이벤트 핸들러 내부에서 사용되는 `this`는 일반적인 자바스크립트 함수 내부의 `this`와 달리 명확하게 정해져 있습니다.
### 🎯 `this`의 의미
jQuery 이벤트 핸들러(예: `click`, `mouseover` 등) 내부에서 사용되는 **`this`**** 키워드**는 \*\*현재 이벤트가 발생한 DOM 요소(element)\*\*를 참조합니다.

| **환경** | **this가 참조하는 것** |
| --- | --- |
| **jQuery 이벤트 핸들러 내부** | **이벤트가 발생한 HTML DOM 요소** (`HTMLElement` 객체) |
| **jQuery 객체로 감쌀 때** | \*\*`$(this)`\*\*를 사용하면 해당 DOM 요소를 **jQuery 객체**로 변환하여 jQuery의 다양한 메서드를 사용할 수 있게 됩니다. |

### 🔍 코드 예시
다음 HTML/CSS 구조를 가정합니다.
### HTML 및 CSS 예시
HTML
```html
<!DOCTYPE html>
<html>
<head>
<style>
  .box {
    width: 100px;
    height: 50px;
    margin: 10px;
    background-color: lightgreen;
    border: 1px solid green;
    cursor: pointer;
  }
</style>
<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script> </head>
<body>
  <div class="box">Box 1</div>
  <div class="box">Box 2</div>

  <script>
    // jQuery 코드
    $('.box').on('click', function() {
      // 1. this는 이벤트가 발생한 '<div>' DOM 요소를 참조
      console.log('클릭된 요소의 태그 이름 (DOM):', this.tagName); // DIV

      // 2. $(this)는 해당 DOM 요소를 jQuery 객체로 감싼 것
      //    -> jQuery 메서드(예: css, text, hide 등) 사용 가능
      $(this).css('background-color', 'yellow');
      $(this).text('클릭됨!');
    });
  </script>
</body>
</html>
```

이 예시에서 두 번째 `div`를 클릭하면, 이벤트 핸들러 내의 `this`는 **두 번째 ****`div`****의 DOM 요소 자체**가 됩니다. 따라서 `$(this)`를 사용하여 그 요소의 배경색을 바꾸고 텍스트를 변경할 수 있는 것입니다.
