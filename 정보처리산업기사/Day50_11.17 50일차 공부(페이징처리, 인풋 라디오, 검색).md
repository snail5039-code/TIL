### 🏷️ 라벨 (Label) 및 초기 선택 (Checked)
- **라벨 사용의 이점:** `<label>` 태그를 사용하면 라벨 텍스트를 클릭했을 때 연결된 입력 요소(예: 체크박스, 라디오 버튼)도 함께 **활성화/비활성화**할 수 있습니다. 이는 사용자의 편의성을 높입니다.
	- **예시 코드:**HTML
		
	```java
<label for="username">사용자 이름:</label>
<input type="text" id="username" name="user">

<input type="checkbox" id="agree" name="terms" checked>
<label for="agree">약관 동의</label>
	```
- **미리 선택:** `checked` 속성을 `<input type="checkbox">` 또는 `<input type="radio">` 태그 안에 추가하면 페이지 로드 시 해당 입력 요소가 **미리 선택된 상태**로 표시됩니다.
	- **예시 코드:**HTML
		
	```java
<input type="radio" id="option2" name="options" value="2" checked>
<label for="option2">선택지 2</label>
	```

### 🧩 JSTL `<c:choose>` 태그
- **용도:** JSP에서 여러 조건 중 **하나**를 선택하여 처리할 때 사용하는 **조건문** 태그입니다.
- **구조:** `<c:choose>` 태그 안에 **하나 이상의** `<c:when>` 태그와 **선택적으로** `<c:otherwise>` 태그를 사용하여 조건을 구성합니다.
	- `<c:when>`: 조건을 명시하며, 이 조건이 **참**일 경우 해당 블록의 내용을 실행합니다. 여러 개를 사용할 수 있으며, **가장 먼저 참이 되는 블록만 실행**됩니다.
	- `<c:otherwise>`: 앞선 `<c:when>` 조건들이 **모두 거짓**일 경우 **마지막에 실행**되는 블록입니다.
	- **예시 코드:**Java
		
	```java
<c:choose>
    <c:when test="${userRole == 'ADMIN'}">
        관리자 메뉴 표시
    </c:when>
    <c:when test="${userRole == 'MEMBER'}">
        일반 회원 메뉴 표시
    </c:when>
    <c:otherwise>
        로그인 메뉴 표시
    </c:otherwise>
</c:choose>
	```

### 🔍 요청 파라미터 접근 및 검증
- **`param`**** 객체:** JSP/JSTL 환경에서 `param` 객체는 현재 웹 요청(Request)에 포함되어 서버로 전달된 **요청 파라미터** (Request Parameter)의 **하나의 값**에 접근할 때 사용됩니다.
	- **예시:** `<c:out value="${param.itemId}"/>`는 요청 URL이나 폼 데이터에서 `itemId`라는 이름의 파라미터 값을 가져옵니다.
- **입력 태그 내 검증 및 값 설정:**
	- `<input>` 태그의 `value` 속성에서 **삼항 연산자** 등을 사용하여 서버 측에서 전달된 값이나 조건에 따라 입력 필드의 **초기값**이나 **상태**를 직접 설정할 수 있습니다.
	- **예시 (JSP/EL 사용):**HTML
		`<input type="text" name="title" value="${param.title != null ? param.title : ''}">`
	- **핵심:** 개발자는 자신이 설정하고 사용해야 할 값을 (예: 폼 제출 시, URL 파라미터로) **올바르게 전달**하고 **수신**할 수 있어야 합니다.

### 📑 페이징 처리 (Paging) 및 검색 기능
- **목표:** 한정된 화면에 전체 데이터를 나누어 보여주고, 사용자가 원하는 부분으로 이동하거나 데이터를 필터링할 수 있도록 합니다.
- **페이지당 게시글 수 (****`itemsInAPage`****):** 한 페이지에 몇 개의 항목을 보여줄지 결정하는 값. (예: **10개**)
### 1. 총 필요한 페이지 수 계산 (버튼 갯수)
- 계산식:
	\$\$\\text\{Total Pages\} = \\lceil \\frac\{\\text\{Total Posts\}\}\{\\text\{Items per Page\}\} \\rceil\$\$
	- JSP/EL 등에서 계산 시: `(int)Math.ceil((double)총 게시글 수 / (double)itemsInAPage)`
	- **예시:** 총 게시글이 103개이고, `itemsInAPage`가 10이라면 \$103/10 = 10.3\$ 이므로, 올림하여 **11 페이지**가 필요합니다.
### 2. 현재 페이지의 시작 인덱스 계산
- **용도:** 데이터베이스 쿼리(예: LIMIT, OFFSET)에서 현재 페이지에 해당하는 게시글을 가져오기 위한 시작 위치(OFFSET)를 계산합니다.
- 계산식:
	\$\$\\text\{Start Index\} = (\\text\{Current Page Number\} - 1) \\times \\text\{Items per Page\}\$\$
### 3. 주소 및 기본값 설정
- **요청 파라미터 (****`Request Parameter`****):** 페이징 및 검색 정보는 주로 URL의 요청 파라미터를 통해 서버로 전달됩니다.
	- **페이징 예시:** `/board?page=3`
	- **검색 예시:** `/board?page=1&searchType=title&searchWord=자바`
- **기본값 (Default Value):** 사용자가 URL에 페이지 번호를 명시하지 않았을 경우를 대비하여, 요청 파라미터의 기본값을 **1** (첫 페이지)로 설정하는 것이 일반적입니다.
### 4. 검색 조건 통합
- 검색 기능을 구현할 때, \*\*검색 조건 (제목, 내용, 제목+내용)\*\*과 **검색 키워드**를 페이징 처리와 함께 유지해야 합니다. 즉, **페이징 버튼**을 누르거나 **페이지 이동** 시에도 **현재 검색 조건과 키워드가 계속 유지**되어야 원하는 결과를 볼 수 있습니다.
	- **예시:** `/board?page=2&searchType=titleContent&searchWord=게시판`
