## HTML 시맨틱 태그 및 CSS 스타일 속성 정리
### 1. 목록 태그: ul, ol, li

| 태그 | 콘텐츠 의미 | 특징 |
| --- | --- | --- |
| ul | Unordered List (순서 없는 목록) | 항목이 \*\*점(∙)\*\*으로 나타납니다. |
| ol | Ordered List (순서 있는 목록) | 항목이 \*\*숫자(1, 2, 3...)\*\*로 나타납니다. |
| li | List Item (목록 항목) | ul 또는 \$\\texttt\{ol\}\$의 **자식**으로 사용되며, \$\\texttt\{li\}\$를 제외한 모든 요소를 자식으로 가질 수 있습니다. |

**ul, ol 태그 활용 예시**
HTML
```html
<ul>
  <li>동물</li>
  <li>식물</li>
  <li>광물</li>
</ul>

<ol>
  <li>물을 끓인다.</li>
  <li>라면을 넣는다.</li>
  <li>후레이크와 스프를 넣는다.</li>
  <li>맛있게 먹는다.</li>
</ol>
```

**ul, li 노말라이즈 (스타일 초기화)**
CSS
```css
ul, li {
  /* 목록 스타일(점, 숫자) 제거 */
  list-style: none;
  /* 안쪽 여백 제거 */
  padding: 0;
  /* 바깥쪽 여백 제거 */
  margin: 0;
}
```

### 2. 헤드라인 태그: h1 \~ h6

| 태그 | 콘텐츠 의미 | 특징 |
| --- | --- | --- |
| h1 \~ h6 | Headline (제목) | 제목의 중요도와 크기를 나타냅니다. \$\\texttt\{h1\}\$이 가장 중요하고 크며, \$\\texttt\{h6\}\$로 갈수록 중요도가 낮아집니다. (크기 조절 목적으로는 잘 쓰이지 않습니다.) |

**h 태그 활용 예시**
HTML
```html
<h1>방탄소년단</h1>

<h2>앨범</h2>
<div>앨범의 자세한 내용</div>

<h2>멤버</h2>
<div>멤버의 자세한 내용</div>
```

**h 태그 노말라이즈 (스타일 초기화)**
CSS
```css
/* h 시리즈 태그에 기본적인 margin을 제거하고 사용합니다. */
h1, h2, h3, h4, h5, h6 {
  margin: 0;
}
```

### 3. 포지션 (위치) 스타일 속성: position

| 종류 | absolute, fixed | relative | static |
| --- | --- | --- | --- |
| **너비** | 내용물만큼 최대한 줄어듭니다. | 그대로 유지됩니다. | 그대로 유지됩니다. |
| **본질** | 유령화 (일반 문서 흐름에서 제거) | 유령의집화 (자리를 유지하며, 이동 기준 제공) | 사람화 (기본 상태) |
| **겹침** | 겹치는 것이 가능합니다. | 겹치는 것이 불가능합니다. | 겹치는 것이 불가능합니다. |
| **이동 기준** | \$\\texttt\{top, left, right, bottom\}\$으로 이동, \\\*\\\*기준은 부모 유령(\$\\texttt\{relative\}\$ 등)\*\*입니다. | \$\\texttt\{top, left, right, bottom\}\$으로 이동, **기준은 현재 위치**입니다. | 이동 속성(top 등)이 적용되지 않습니다. |

- **z-index**: position 속성이 적용된 요소들(absolute, fixed, relative)의 겹침 순서를 지정합니다. 숫자가 클수록 사용자에게 가까이(위에) 보입니다. (상대적인 값입니다.)
**position 및 z-index 예제 코드**
HTML
```html
<section>
  <div></div>
  <div></div>
  <div></div>
  <div></div>
</section>
```

CSS
```css
section {
  border: 10px solid blue;
  width: 500px;
  height: 500px;
  position: relative; /* 자식 absolute의 기준점 */
  margin-top: 20px;
}

section > div {
  border: 10px solid red;
  position: absolute; /* 유령화 */
  top: 0; left: 0; right: 50%; bottom: 50%; /* 기본 크기/위치 설정 */
}

section > div:nth-child(1) { background-color: black; }

section > div:nth-child(2) {
  background-color: green;
  top: 10%; left: 10%; right: 40%; bottom: 40%;
  z-index: 1; /* 겹침 순서 1 */
}

section > div:nth-child(3) {
  background-color: pink;
  top: 20%; left: 20%; right: 30%; bottom: 30%;
}

section > div:nth-child(4) {
  background-color: gold;
  top: 30%; left: 30%; right: 20%; bottom: 20%;
  z-index: 2; /* 겹침 순서 2 (가장 위) */
}
```

### 4. 변형 속성: transform: translate(x, y)
\$\\texttt\{transform: translate(x, y)\}\$는 요소를 \$\\texttt\{x\}\$축과 \$\\texttt\{y\}\$축을 따라 이동시키는 데 사용됩니다.
- **translate(x, y)**: \$\\texttt\{x\}\$축으로 \$\\texttt\{x\}\$만큼, \$\\texttt\{y\}\$축으로 \$\\texttt\{y\}\$만큼 이동합니다.
- **translateX(x)**: \$\\texttt\{x\}\$축으로만 이동합니다.
- **translateY(y)**: \$\\texttt\{y\}\$축으로만 이동합니다.
- **특징**: position 이동과 달리, **요소의 원래 자리는 유지**된 채 시각적인 위치만 변경됩니다. **레이아웃에 영향을 주지 않으며**, 주로 중앙 정렬이나 성능이 중요한 애니메이션에 사용됩니다.
**transform: translate 예제 코드**
HTML
```html
<div class="box-container">
    <div class="box box1">기준 위치</div>
    <div class="box box2">translate(50px, 50px)</div>
    <div class="box box3">translateX(-50%)</div>
</div>
```

CSS
```css
.box-container {
    width: 400px;
    height: 200px;
    border: 3px dashed #ccc;
    position: relative;
    margin-top: 50px;
}

.box {
    width: 100px;
    height: 50px;
    color: white;
    text-align: center;
    line-height: 50px;
    position: absolute;
    top: 50px;
    left: 50px;
}

.box1 { background-color: gray; z-index: 1; }

.box2 {
    background-color: tomato;
    /* 오른쪽 50px, 아래 50px 이동 */
    transform: translate(50px, 50px); 
}

.box3 {
    background-color: green;
    top: 100px;
    left: 200px;
    /* 자신의 너비의 -50% 만큼 x축 이동 (중앙 정렬에 유용) */
    transform: translateX(-50%); 
}
```
