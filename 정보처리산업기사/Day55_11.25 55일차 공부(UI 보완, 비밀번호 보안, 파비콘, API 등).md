### 2. 보안 및 인증 (Security & Auth)
사용자의 민감한 정보를 보호하고, 안전하게 로그인하는 과정입니다.
### **SHA256 (암호화)**
비밀번호를 데이터베이스에 평문으로 저장하면 안 됩니다. SHA256은 단방향 해시 알고리즘으로, 복호화가 불가능하여 보안성이 높습니다. (실무에서는 Salt를 추가하여 보안을 더 강화합니다.)
Java
```javascript
import java.security.MessageDigest;

public String encryptSHA256(String text) throws Exception {
    MessageDigest md = MessageDigest.getInstance("SHA-256");
    md.update(text.getBytes());
    
    StringBuilder builder = new StringBuilder();
    for (byte b : md.digest()) {
        builder.append(String.format("%02x", b));
    }
    return builder.toString();
}
```

### **추가: Firebase Login API**
구글, 페이스북 등 소셜 로그인을 손쉽게 구현할 수 있는 플랫폼입니다. 프론트에서 토큰을 받아 백엔드에서 검증하는 방식이 일반적입니다.
JavaScript
```javascript
// Firebase 초기화 및 로그인 (Frontend)
import { initializeApp } from "firebase/app";
import { getAuth, signInWithPopup, GoogleAuthProvider } from "firebase/auth";

const firebaseConfig = { /* ...키 설정... */ };
const app = initializeApp(firebaseConfig);
const auth = getAuth(app);

const loginWithGoogle = () => {
    const provider = new GoogleAuthProvider();
    signInWithPopup(auth, provider)
        .then((result) => {
            const user = result.user;
            console.log("로그인 성공:", user);
            // 이후 user.accessToken을 백엔드로 전송하여 검증
        }).catch((error) => {
            console.error("에러:", error);
        });
};
```

### 3. 외부 데이터 및 지도 연동 (External APIs)
외부 서비스를 우리 서비스로 가져오는 핵심 작업입니다.
### **공공데이터포털 API & WebClient**
기존의 `RestTemplate`보다 최신 기술인 **WebClient**는 비동기(Non-blocking) 방식을 지원하여 성능이 우수합니다. 공공데이터(날씨, 교통정보 등)를 가져올 때 사용합니다.
> ⚠️ 중요 체크 (작업 36 핵심):<br>API 응답이 올 때, 데이터가 없거나 구조가 다를 경우 NullPointerException이 발생할 수 있습니다. \*\*"빈 객체가 생성되지 않았으면 수동으로 만들어야 한다"\*\*는 점은 DTO 매핑 시 기본 생성자를 초기화하거나, Optional 처리를 통해 안전하게 데이터를 받아야 함을 의미합니다.
Java
```javascript
// Spring WebFlux (WebClient) 예시
import org.springframework.web.reactive.function.client.WebClient;

public void fetchPublicData() {
    WebClient webClient = WebClient.create("http://apis.data.go.kr");

    String response = webClient.get()
            .uri(uriBuilder -> uriBuilder
                    .path("/sample/api/path")
                    .queryParam("serviceKey", "YOUR_API_KEY")
                    .build())
            .retrieve()
            .bodyToMono(String.class) // 비동기로 데이터 수신
            .block(); // 필요시 동기 처리 (테스트 등)
    
    // 데이터 파싱 시 null 체크 필수!
    if (response == null || response.isEmpty()) {
        // 빈 객체 수동 생성 로직 또는 예외 처리
        response = "{}"; 
    }
}
```
