## **테이블 구조 변경 (ALTER TABLE)**
`ALTER TABLE` 구문은 기존 테이블의 구조를 변경할 때 사용합니다.
- **컬럼 추가**: `ADD COLUMN`을 사용해 새로운 컬럼을 추가합니다.
	- `ALTER TABLE article ADD COLUMN id INT;`
- **컬럼 위치 변경**: `MODIFY COLUMN`을 사용하고, `FIRST` 또는 `AFTER` 키워드를 사용해 컬럼의 위치를 변경할 수 있습니다.
	- `ALTER TABLE article MODIFY COLUMN id INT FIRST;` (가장 앞으로 이동)
	- 중간에 위치를 끼워 넣을 때는 `AFTER` 키워드 뒤에 기준이 되는 컬럼 이름을 씁니다.
- **컬럼 삭제**: `DROP COLUMN`을 사용해 특정 컬럼을 삭제합니다.
	- `ALTER TABLE article DROP COLUMN id;`
	- **참고**: 같은 테이블 내에 동일한 이름의 컬럼은 존재할 수 없으므로, 삭제 시에는 컬럼의 데이터 타입을 명시할 필요가 없습니다.

## **제약조건 (Constraints)**
제약조건은 테이블에 저장되는 데이터의 무결성을 보장하기 위해 사용됩니다.
- **기본 키 (Primary Key, PK)**: 각 행을 고유하게 식별하는 키입니다.
	- 테이블당 하나만 존재할 수 있습니다.
	- **`NULL`**** 값을 허용하지 않습니다.**
	- 컬럼에 PK 제약조건을 추가하는 방법은 두 가지입니다.
		- `ALTER TABLE article MODIFY COLUMN id INT PRIMARY KEY;`
		- `ALTER TABLE article ADD PRIMARY KEY(id);`
- **외래 키 (Foreign Key, FK)**: 다른 테이블의 기본 키를 참조하는 키입니다. 테이블 간 관계를 설정할 때 사용됩니다.
- **`AUTO_INCREMENT`**: 정수 타입의 컬럼에 자동으로 1씩 증가하는 값을 할당합니다. 주로 기본 키와 함께 사용됩니다.
	- `ALTER TABLE article MODIFY COLUMN id INT AUTO_INCREMENT;`
- **`UNSIGNED`**: 정수형 컬럼에 음수 값을 허용하지 않고, 양수만 저장하도록 합니다.
	- `ALTER TABLE article MODIFY COLUMN id INT UNSIGNED AUTO_INCREMENT;`
- **`NOT NULL`**: 해당 컬럼에 `NULL` 값 저장을 금지합니다.
- **`DEFAULT`**: 컬럼에 값을 명시하지 않았을 때 자동으로 입력될 기본값을 설정합니다.
	- `ALTER TABLE article MODIFY COLUMN test VARCHAR(20) NOT NULL DEFAULT 'test';`
- **`COMMENT`**: 컬럼에 대한 설명을 추가합니다. 데이터베이스 스키마를 문서화하는 데 도움이 됩니다.
	- `ALTER TABLE article MODIFY COLUMN test VARCHAR(20) NOT NULL DEFAULT 'test' COMMENT '이 컬럼은 테스트용이다';`
	- 주석처럼 보이지만, 스키마 정보에 저장되어 조회할 수 있습니다.

## **기타 유용한 기능**
- **컬럼 이름 변경**: `CHANGE` 키워드를 사용해 컬럼 이름과 데이터 타입을 한 번에 변경할 수 있습니다.
- **`TRUNCATE`**: 테이블의 모든 행을 삭제하며, `AUTO_INCREMENT` 값을 초기화합니다. `DELETE`와 달리 `WHERE` 절을 사용할 수 없어 전체 테이블을 빠르게 비울 때 유용합니다.
- **`NOW()`**: 현재 날짜와 시간을 반환하는 함수입니다.
- **`DUAL`**: 오라클에서 사용되는 가상의 테이블로, 테이블을 참조하지 않고 함수나 계산 결과를 조회할 때 사용됩니다. MySQL에서는 굳이 필요하지 않습니다.

## **데이터 조회 (SELECT)**
데이터베이스에서 원하는 데이터를 검색할 때 사용하는 기본 구문입니다.
- **정렬**: `ORDER BY`를 사용해 조회 결과를 특정 컬럼 기준으로 정렬합니다.
	- `ASC`: **오름차순 정렬** (기본값)
		- `SELECT * FROM article ORDER BY id ASC;`
	- `DESC`: **내림차순 정렬**
		- `SELECT * FROM article ORDER BY id DESC;`
- **패턴 검색**: `LIKE` 연산자를 사용해 특정 패턴을 포함하는 데이터를 찾습니다.
	- `%`: 0개 이상의 문자를 의미하는 와일드카드입니다. 🕵️‍♂️
		- `SELECT * FROM article WHERE title LIKE '%목%';` (제목에 '목'이 **포함**된 데이터)
		- `LIKE '목%';` ('목'으로 **시작**하는 데이터)
		- `LIKE '%목';` ('목'으로 **끝나는** 데이터)
