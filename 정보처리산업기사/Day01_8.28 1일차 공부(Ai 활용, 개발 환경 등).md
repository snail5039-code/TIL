### **1. AI 활용과 개발의 미래**
최근 개발 분야에서는 **AI를 활용한 개발 방식**이 주목받고 있습니다.
- **바이브 코딩(Vibe Coding)**: 개발자가 전적으로 AI의 도움을 받아 코드를 작성하는 방식입니다. AI가 생성한 코드는 **기능적으로는 괜찮지만** 단편적인 경우가 많아, 개발자가 전체적인 맥락을 파악하고 **입체적으로 다듬어**야 완성도 높은 결과물을 만들 수 있습니다.

### **2. 개발 환경 파악**
개발은 개발할 수 있는 상황, 개발에 필요한 것들을 준비하는 것이다.
개발 환경은 주로 \*\*운영체제(OS)\*\*에 따라 구분됩니다. 각각의 특징과 개발자들이 선호하는 경향은 다음과 같습니다.
- **Linux**: 주로 **서버**에 사용되는 (기계 친화적)운영체제입니다. 서버는 사용자의 요청에 응답하는   역할을 합니다.
- **Windows**: **사용자 친화적**인 운영체제입니다. 서버로도 사용할 수 있지만, 시스템 용량이 커져 비효율적일 수 있습니다.
- **macOS**: **기계 친화적**인 운영체제입니다.
- **부가 설명**: 개발자들이 Windows와 macOS 중 어느 것을 선호하는지에 대한 질문은 답변하기 어렵습니다. 특정 프로그램의 **호환성** 때문에 선호도가 갈리기도 합니다. Windows의 `cmd`나 `파워쉘`은 제한이 있어 `Git Bash` 같은 추가 프로그램이 필요한 반면, macOS의 터미널은 자유롭게 사용할 수 있다는 장점이 있습니다.
- \* Window : 일반적인 프로그램, Mac : 개발에 사용되는 주요 프로그램

### **3. 웹 개발 용어 및 개념**
- \*웹 개발(Web)과 웹앱 개발(Web App)\*\*은 기본적으로 같은 개념입니다. 그러나 **웹/앱 개발**은 웹과 앱을 모두 개발하는 것을 의미하므로 다른 개념입니다.
- **CLI 환경 (Command Line Interface)**: 그래픽 사용자 인터페이스(GUI) 대신 키보드로 명령어를 입력하여 컴퓨터와 상호 작용하는 방식입니다.
- **부가 설명**: 웹 개발은 웹 브라우저를 통해 접근하는 애플리케이션을 만드는 것이고, 앱 개발은 스마트폰에 설치하는 애플리케이션을 만드는 것입니다. 최근에는 웹과 앱의 경계가 모호해지고 있으며, 하나의 코드로 여러 플랫폼에서 작동하는 **반응형 웹** 기술이 많이 사용됩니다.

### **4. 개발에 필요한 필수 도구**
1. **자바(Java) 설치**:
	- \*자바(JAVA)\*\*는 컴퓨터와 소통하기 위한 **프로그래밍 언어**입니다.
	- 컴퓨터가 자바 언어를 이해하고 실행할 수 있도록 \*\*자바 개발 도구(JDK)\*\*를 설치해야 합니다.
	- **JDK(Java Development Kit)**: 개발과 실행이 모두 가능합니다.
	- **JRE(Java Runtime Environment)**: 자바 실행 환경으로, 실행만 가능합니다.
2. **IDE(통합 개발 환경)**:
	- 코드를 작성, 번역(컴파일), 실행 결과를 확인할 수 있는 프로그램입니다.
	- 대표적인 IDE로는 **STS(이클립스 기반)**, **이클립스**, **인텔리J** 등이 있습니다.
	- **인텔리J**는 유료 버전이 있으나, 제한된 기능의 무료 버전도 제공됩니다.
	- **STS 설치 후 인코딩(encoding)을 ****`UTF-8`****로 설정하는 것이 중요합니다.** `UTF-8`은 다양한 문자를 깨지지 않고 표현하기 위한 표준입니다.

### **5. 프로그래밍 언어의 종류 및 특징**
프로그래밍 언어는 크게 **저급 언어**와 **고급 언어**로 나뉩니다.
- **저급 언어 (기계 친화적)**
	- **C언어**: 모든 언어의 기초로 불리며, 기계 친화적이라 **임베디드(내장형) 시스템**에 특화되어 있습니다.
	- **임베디드 시스템**: 특정 목적을 위해 하드웨어와 소프트웨어가 결합된 컴퓨터 시스템으로, 가전제품, 자동차, 로봇 등에 사용됩니다. 예를 들어, 냉장고의 온도를 조절하는 작은 컴퓨터 칩이 바로 임베디드 시스템입니다.
- **고급 언어 (사람 친화적)**
	- **자바(Java)**: 웹 개발에 특화되어 있으며, 제한 사항이 많아 처음 만들기는 어렵지만, **유지보수**가 용이합니다.
	- **파이썬(Python)**: \*\*인공지능(프로토타입)\*\*과 **빅데이터** 분야에 특화되어 있습니다. 제한 사항이 거의 없어 배우기 쉽고 자유롭습니다. 최근에는 \*\*장고(Django)\*\*와 같은 웹 프레임워크를 통해 웹 개발에도 많이 사용됩니다.

### **6. 자주 사용되는 명령어 및 시스템 파악**
- **명령 프롬프트(Windows) 사용 예시**:
	- `netstat -na`, `netstat -nao`: 자신의 컴퓨터와 연결된 모든 네트워크 연결을 보여주는       명령어
	- \* nao를 쓰면 ip, port, pid를 확인할 수 있다. 
	- 포트번호 : 순간이동을 할 수 있는 포탈 같은 느낌, 포트로 접근하면 이동할 수 있다.
	- `md`: 파일 생성
	- `rd`: 파일 삭제
	- `cd`: 디렉토리(폴더) 이동
	- `dir`: 디렉토리(폴더) 내용 확인
	- `ipconfig` : 현재 내 컴퓨터가 사용 중인 ip 확인 
- **프로세스 및 우선순위 확인**:
	- Windows의 **작업 관리자**에서 `세부 정보` 탭을 통해 실행 중인 프로세스와 그 우선순위를 확인할 수 있습니다.
	- 프로세스 : 실행 중인 프로그램 (PID), 프로세스가 정상적으로 작동하려면 포트 번호가 중복되면 안된다.
