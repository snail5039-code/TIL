## 💻 웹 자원 식별 및 위치 (URI, URL, URN)
- **URI (Uniform Resource Identifier):** **자원을 식별**하기 위한 문자열의 가장 큰 범위입니다. 인터넷상의 자원을 고유하게 구분합니다.
- **URL (Uniform Resource Locator):** URI의 하위 개념으로, 자원의 **위치**를 명시하여 접근 방법을 포함합니다. 웹 주소(Protocol, Host, Port, Path 등)가 여기에 해당합니다.
	- **예시:** `https://www.example.com/board/list`
- **URN (Uniform Resource Name):** URI의 하위 개념으로, 자원의 **이름**만을 명시하며 위치와는 독립적입니다. 현재는 널리 사용되지 않습니다.
> 핵심: URI가 URL보다 더 큰 범위의 개념입니다.

## 📨 데이터 전송 방식 (POST)
- **POST 방식 사용:** 웹 브라우저에서 서버로 데이터를 보낼 때, 특히 **데이터를 생성/수정**하거나 **보안**이 필요한 경우에 사용합니다. 전송 데이터가 URL에 노출되지 않아 GET 방식보다 안전합니다.
### **➕ 추가: 폼 데이터를 POST로 넘기기**
HTML `<form>` 태그의 `method` 속성을 `post`로 설정하여 데이터를 전송합니다.
**예시 코드 (HTML):**
HTML
```java
<form action="/article/doWrite" method="post">
    <label for="title">제목:</label>
    <input type="text" id="title" name="title"><br>
    <label for="body">내용:</label>
    <textarea id="body" name="body"></textarea><br>
    <button type="submit">작성</button>
</form>
```

## 🌟 웹페이지 이동 및 리턴값 처리
### **✨ 디테일 로직 후 String Format 사용**
컨트롤러(Controller)에서 로직 처리 후 **사용자에게 보여줄 메시지나 이동할 페이지 경로**를 반환할 때, 단순히 문자열을 반환하는 것보다 **`String.format()`** 등을 사용하여 메시지를 동적으로 구성하고 리턴하면 유연성과 가독성이 높아집니다.
**예시 코드 (Java/Spring Controller):**
Java
```java
@PostMapping("/article/doWrite")
public String doWrite(Article article) {
    long newId = articleService.write(article);
    // String.format을 사용하여 성공 메시지 및 리다이렉트 경로 구성
    String msg = String.format("%d번 글이 작성되었습니다.", newId);
    // 자바스크립트 alert 후 게시글 디테일 페이지로 리다이렉트 (가정)
    return "redirect:/article/detail?id=" + newId + "&msg=" + msg; 
    // 또는 공통 유틸을 사용하여 JS alert 후 리다이렉트 처리 (권장)
}
```

### **🔄 작성 후 찾아가기 (MyBatis)**
게시글 작성(INSERT) 후 방금 \*\*생성된 글의 고유 ID(Primary Key)\*\*를 가져와 해당 상세 페이지로 이동할 때 사용합니다. \*\*`SELECT LAST_INSERT_ID()`\*\*는 MySQL에서 가장 최근에 **현재 세션**에서 성공적으로 실행된 `INSERT` 쿼리의 자동 증가(Auto-Increment) ID 값을 반환합니다.
**예시 코드 (MyBatis XML Mapper):**
XML
```java
<insert id="insertArticle" useGeneratedKeys="true" keyProperty="id">
    INSERT INTO article (title, body, regDate, updateDate)
    VALUES (#{title}, #{body}, NOW(), NOW())
</insert>

<select id="getLastInsertId" resultType="long">
    SELECT LAST_INSERT_ID()
</select>
```

## 📄 View(JSP) 및 공통 요소 처리
### **🏷️ 페이지 타이틀 동적 설정**
공통 헤더 파일(header include)을 사용하고, 개별 페이지의 `<title>` 태그 내용을 동적으로 설정할 때 유용합니다.
**예시 코드 (JSP):**
1. **개별 페이지에서 변수 설정:**Java
	```java
<c:set var="pageTitle" value="게시글 작성"/>
	```
2. **헤더 파일(include)에서 사용:**HTML
```java
<!DOCTYPE html>
<html lang="ko">
<head>
    <title>${pageTitle } | 우리 사이트명</title> 
    </head>
```
### **➡️ 리다이렉트 (Redirect)**
- **사용 상황:** 주로 **데이터 변경(POST)** 요청 처리 후 **새로운 GET 요청**으로 브라우저를 이동시킬 때 사용합니다. (예: 게시글 작성/수정 후 상세 페이지 또는 목록 페이지로 이동).
- **목적:** 사용자가 **새로고침**했을 때 직전의 POST 요청이 다시 실행되는 것을 **방지**합니다 (PRG 패턴: Post-Redirect-Get).
	- **예시:** `return "redirect:/article/list";`

## 🛠️ 공통 기능 및 유틸리티
### **📦 반복적인 기능 유틸리티화**
데이터 처리, 검증, 메시지 반환 등 **반복적으로 사용되는 코드**는 **별도의 유틸리티 클래스**로 분리하여 재사용성과 유지보수성을 높이는 것이 좋습니다.
**예시:** JSON 응답 포맷을 일관되게 만들어주는 `ResultData` 또는 `Util` 클래스.
### **🧩 가변 인자 (Object...)**
Java에서 메서드를 정의할 때 `Object...`와 같이 **가변 인자**를 사용하면 **인수의 개수에 상관없이** 여러 개의 인수를 전달받을 수 있습니다. 이는 유틸리티 메서드에서 다양한 타입의 인수를 처리하거나, 유연한 로깅 등을 구현할 때 유용합니다.
**예시 코드 (Java):**
Java
```java
// ... objects는 내부적으로 Object[] 배열로 처리됩니다.
public static void printArgs(String message, Object... objects) {
    System.out.println(message);
    for (Object obj : objects) {
        System.out.println(" - " + obj.toString());
    }
}

// 사용 예:
printArgs("로그 정보:", 1, "제목", new Date());
```

## 💡 폼 데이터와 JavaScript/jQuery
### **❓ Form으로 받은 것을 jQuery로 받을 수 있나?**
**네, 가능합니다.**
`form` 태그를 통해 전송된 데이터는 \*\*서버 측 (Controller)\*\*에서 받아서 처리하는 것이 기본입니다.
하지만 \*\*전송 전에 클라이언트 측 (브라우저)\*\*에서 jQuery를 사용하여 폼의 입력 필드 값을 읽거나, 폼 데이터를 직렬화하여 **Ajax** 방식으로 서버에 전송할 수 있습니다.
**예시 코드 (jQuery/JavaScript):**
JavaScript
```javascript
// 1. 특정 필드의 값 읽기
let titleValue = $('#title').val(); 
console.log("읽어온 제목:", titleValue);

// 2. 폼 데이터를 직렬화하여 서버에 Ajax로 전송
$('#myForm').submit(function(e) {
    e.preventDefault(); // 기본 폼 전송 막기
    
    let formData = $(this).serialize(); // 폼 데이터를 "key=value&..." 형태로 직렬화

    $.ajax({
        type: "POST",
        url: "/article/doWriteAjax",
        data: formData,
        success: function(response) {
            console.log("성공", response);
            // 성공 후 동작 (예: 목록 새로고침)
        },
        error: function(xhr, status, error) {
            console.error("에러 발생", error);
        }
    });
});
```
